# DEMO-001：デザインコンセプト（2案）

## 案A：写真中心・シズル感重視

- 狙い：焼きたてパンの魅力を視覚的に伝える
- ターゲット：近隣の30〜50代
- キーメッセージ：「焼きたての香りに、ちょっと寄り道」
- ビジュアル方針：パン写真を大きく、余白は控えめ
- 配色：ベージュ×ブラウン
- メリット：食欲訴求が強い／リスク：写真がないと成立しない（今回はプレースホルダーで代替）
- 推奨媒体：チラシ・Instagram

## 案B：テキスト中心・情報整理重視

- 狙い：営業時間・場所・新商品情報を確実に伝える
- ターゲット：近隣の30〜50代
- キーメッセージ：「近所に、もう一つの落ち着ける場所」
- ビジュアル方針：アイコン中心、写真依存度を下げる
- 配色：ベージュ×深緑
- メリット：写真素材がなくても成立する／リスク：食欲訴求が弱い
- 推奨媒体：チラシ・LP

## 採用案

デモでは**案B**（写真素材がないため）をベースに、案Aの配色要素を一部取り入れて制作する。

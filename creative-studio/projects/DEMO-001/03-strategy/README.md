# DEMO-001：ブランド方針・導線設計（架空案件）

## ブランド方針（仮定）

- ブランド人格：素朴で温かい、近所の人に寄り添う
- トーン：丁寧語だが堅すぎない。「〜です」「〜ますよ」
- 配色（仮定）：ベージュ×ブラウン×深緑（自然・温かみ）
- 禁止表現：効果保証表現、架空の「行列店」等の実績表現

## 導線設計

- 顧客課題（仮説）：在宅ワークの合間に落ち着けるカフェが近所にない
- 訴求軸：焼きたてパン＋長居できるイートイン
- オファー：季節限定パンの紹介（新商品の認知）
- 導線：チラシ／Instagram投稿 → 来店 or Instagramフォロー
- CTA：来店、Instagramフォロー
- KPI（仮置き・実績値なし）：チラシ配布後2週間のInstagramフォロワー増加数（仮の目標値、
  検証データなしのため参考値扱い）

## 分類

- **確認済み事実**：なし
- **仮定**：上記すべて
- **未確認事項**：実際の顧客層、実際のKPI基準値

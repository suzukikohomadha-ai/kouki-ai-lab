# トラブルシューティング

## 環境構築まわり

| 症状 | 確認事項 | 対応 |
|---|---|---|
| `node` コマンドが見つからない | Node.jsの有無（`node -v`） | https://nodejs.org/ からLTS版を導入 |
| `git` コマンドが見つからない | Gitの有無（`git --version`） | https://git-scm.com/ から導入（初回構築時点では未インストールでした） |
| 画像生成・Figma等が使えない | `.env` の設定、MCP/外部ツール接続状況 | 未接続の間はHTML/CSS/SVG・制作指示書・生成用プロンプトで代替する |

## 検証スクリプトまわり

| 症状 | 原因の可能性 | 対応 |
|---|---|---|
| `check-secrets.mjs` が大量にヒットする | 誤検知（16進数のID・カラーコード等） | 1件ずつ内容を確認。シークレットでなければ無視（削除はしない） |
| `check-links.mjs` でローカル参照がNGになる | 相対パスの誤り、ファイル未作成 | パスを見直す。まだ作成していない参照先なら先に作成する |
| `validate-design-tokens.mjs` でコントラストが不合格 | 配色がWCAG基準を満たしていない | `brand/design-tokens.json` の色を見直す（特にtextPrimary/background） |
| `generate-asset-manifest.mjs` で未登録が大量に出る | 台帳登録が追いついていない | `brand/sources/source-register.md` に一括で追記する |

## 制作物まわり

- 「入稿できるはずが仕様が違う」と言われた場合は、`templates/flyer-specification.md` の
  入稿仕様が「暫定仕様」のまま確定されていないか確認してください。
- 「表示が崩れる」と言われた場合は、実際にブラウザ等で確認済みかどうかをまず確認してください
  （`[実機未確認]` のまま納品されていないか）。

## エスカレーション

法的問題・個人情報漏えい・重大なブランド毀損リスクが疑われる場合は、即座に該当ファイルの
公開・入稿・配布を止め、`creative-director` を通じてユーザーに報告してください。

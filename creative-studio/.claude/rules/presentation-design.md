# プレゼンテーション制作ルール

## 制作前に定義すること

誰が読むか、誰が説明するか、読後に何を判断してほしいか、発表時間、配布の有無、
提案・報告・説明のどれか、必須情報、機密情報、出力形式。

## 標準構成（内容に応じて調整）

表紙 → 要約 → 背景 → 課題 → 分析 → 提案 → 実施内容 → スケジュール → 費用 →
効果測定 → リスク → 次のアクション。

ページ数を埋めるために不要なスライドを増やさない。

## 表現ルール

- ユーザーが提供していない数値をグラフ化しない
- 概念図と実データのグラフを明確に区別する（データ由来を明記）
- 各スライドには原則として1つの主要メッセージを設定する
- データの出典は該当スライドまたは巻末に記載する

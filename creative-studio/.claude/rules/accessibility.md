# アクセシビリティルール

## 共通（印刷物・画像・資料・Web共通）

- 背景と文字のコントラストを確保する（`scripts/validate-design-tokens.mjs` で
  テキスト色×背景色のコントラスト比を機械的にチェックできる）
- 色だけで状態・意味を表現しない（アイコンやテキストを併記する）
- 小さい文字に重要情報を詰め込まない
- 情報の優先順位を明確にし、視線誘導を意識する

## Web / LP

- モバイルファーストで検討する
- キーボード操作を考慮する（フォーカス順序・操作可能要素の明示）
- 意味のあるHTML構造を使用する（見出し階層、`<button>`/`<a>` の使い分け等）
- 画像に代替テキスト（alt）を設定する
- フォームのラベルを省略しない
- 過剰なアニメーションを避ける（`prefers-reduced-motion` を考慮）
- 読み込み中・エラー状態を設計する
- CTAを過度に繰り返さない、不要なポップアップを使わない

## 画像・SNS投稿

- テキストを含む画像には、投稿本文側にも同内容の代替テキストを用意する
- 文字入り画像は原則、背景素材とテキストを別工程にし、後から読みやすさを調整できるようにする

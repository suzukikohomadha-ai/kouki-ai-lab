# marketing-plan：マーケティング導線設計

## 目的

`marketing-strategist` として、`templates/campaign-plan.md` を使って導線設計を整理する。

## 手順

1. `creative-intake` の結果を確認する。
2. 顧客課題の仮説、訴求軸、オファーを整理する。
3. カスタマージャーニー（`templates/customer-journey.md`）に沿って導線を設計する。
4. CTAを決め、KPI（実績値／業界参考値／仮置きの目標値を区別）を設定する。
5. 計測方法・改善仮説（A/Bテスト案があれば仮説／変更箇所／評価指標／判定条件を明記）を整理する。

## 出力

`templates/campaign-plan.md` を埋めたもの（顧客課題、訴求軸、オファー、導線、CTA、KPI、
計測方法、改善仮説）

## 実行例

```text
/marketing-plan このチラシを使った集客導線を設計して
```

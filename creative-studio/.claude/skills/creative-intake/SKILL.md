# creative-intake：制作ヒアリング

## 目的

`creative-director` として、`templates/creative-brief.md` を使ってヒアリング結果を整理する。

## 手順

1. 以下を確認する（既に分かっている情報は聞き直さない）。
   - **事業情報**：会社名・ブランド名／商品・サービス／対応地域／価格／強み／
     競合との違い／実績／許認可／問い合わせ方法
   - **制作目的**：認知／問い合わせ／購入／予約／LINE登録／資料請求／採用／
     イベント集客／商談／社内説明
   - **ターゲット**：年齢・性別・地域・職業・状況・課題・不安・比較対象・行動を妨げる要因
     （根拠がなければ「想定ターゲット」として仮定を明示）
   - **掲載媒体**：紙／店頭／ポスティング／Instagram／LINE／Google広告／Meta広告／
     YouTube／Webサイト／営業資料／展示会／メール
   - **デザイン**：希望イメージ／避けたいイメージ／ブランドカラー／ロゴ／使用写真／
     参考デザイン／フォント／縦横比／サイズ／納品形式
   - **CTA**：電話／QRコード／LINE／問い合わせフォーム／購入／予約／来店／資料請求
2. 重要度の低い不明点まで質問して作業を止めない。合理的な仮定は明示して進める。
3. `templates/creative-brief.md` の様式で整理し、案件フォルダ（`projects/<案件ID>/01-brief/`）に保存する。

## 出力

制作目的、ターゲット、媒体、CTA、掲載情報、必要素材、不足情報、仮定、制作スケジュール、
成果物一覧。

## 実行例

```text
/creative-intake 新商品のチラシを作りたい
```

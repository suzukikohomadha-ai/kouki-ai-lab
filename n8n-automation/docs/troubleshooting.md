# トラブルシューティング

## 環境構築まわり

| 症状 | 確認事項 | 対応 |
|---|---|---|
| `node` コマンドが見つからない | Node.jsがインストールされているか（`node -v`） | https://nodejs.org/ からLTS版を導入 |
| `git` コマンドが見つからない | Gitがインストールされているか（`git --version`） | https://git-scm.com/ から導入（このプロジェクトの初回構築時点では未インストールでした） |
| `claude --version` が実行できない | PATHが通っているか、実行環境（VSCode拡張/SDK等）の種類 | 実行環境のドキュメントを確認。バージョン確認が必須でない作業は先に進めてよい |
| n8n APIに接続できない | `.env` の `N8N_BASE_URL` / `N8N_API_KEY` が設定されているか、n8n側でAPIアクセスが有効か | n8n管理画面でAPIキーを発行し `.env` に設定（`.env` はGit管理外） |

## 検証スクリプトまわり

| 症状 | 原因の可能性 | 対応 |
|---|---|---|
| `validate-workflow.mjs` がJSON構文エラーを出す | ワークフローJSONが壊れている／末尾カンマ等 | エディタの構文チェック機能で確認。n8n上で開けるかも確認 |
| `check-secrets.mjs` が大量にヒットする | 誤検知（16進数のIDやハッシュ値等） | 1件ずつ内容を確認。シークレットでなければ無視してよいが、削除はしない |
| `compare-workflows.mjs` の差分が期待と違う | ノード名が変わっている（同一ノードとして認識できない） | ノード名の変更履歴を確認。名前変更と内容変更を分けて記録する |

## n8n運用まわり（Hooks・自動化に依存する場合）

- Hooksは現時点で未実装・無効です。「自動でトリガーされるはずが動かない」という報告があった
  場合は、まずHooksが本当に有効化されているか（`.claude/settings.json` の `hooks`）を確認してください。
- ワークフローが「実行されたはずなのに結果が反映されない」場合は、
  1. n8nの実行履歴（Execution）を確認する `[要インスタンス確認]`
  2. エラーが出ていないか確認する
  3. Credentialの有効期限切れ・権限不足がないか確認する
  の順に切り分けてください。

## エスカレーション

上記で解決しない、または重大な問題（データ損失・セキュリティインシデントの疑い）の場合は、
即座にワークフローを無効化し、`n8n-automation-lead` を通じてユーザーに報告してください。

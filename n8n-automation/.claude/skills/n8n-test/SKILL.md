# n8n-test：テスト・ステージング検証

## 目的

`workflows/validated/` のワークフローを、ステージング環境で実際にテストし、
結果を `tests/results/` に記録する。**実行していないテストを「成功」と書かない。**

## 前提条件（事前に確認）

- ステージング環境のn8nに接続できるか（`[ユーザー入力待ち]` の場合はここで停止し確認を依頼する）
- Credentialがステージング用に割り当てられているか（本番Credentialを流用しない）
- `.env` に `N8N_BASE_URL` / `N8N_API_KEY` 等が設定されているか

## 手順

1. `tests/cases/` のテストケース（正常系・異常系・境界値・空データ・欠損データ・重複データ・
   大量データ・APIタイムアウト・認証エラー・レート制限・外部サービス障害・部分失敗・
   再実行・手動復旧・ロールバック）を確認する。
2. 実行前にワークフローのバックアップ（エクスポート）を取る。
3. ステージング環境へインポートし、Credentialを割り当てる。
4. テストケースを実行し、実際の出力を記録する。
5. 各テスト結果には、実行したコマンド／操作・実行日時・対象環境・入力データ・
   実際の出力・成否・残存リスクを必ず記載する（`.claude/rules/documentation.md` 準拠）。
6. `tests/results/<日付>_<案件名>.md` に結果をまとめる。

## 入力

`workflows/validated/*.json` と `tests/cases/*`

## 出力

`tests/results/*`（実行日時・入力・実際の出力・成否・残存リスクを含む）

## 実行例

```text
/n8n-test workflows/validated/invoice-processing.json
```

## 次のフェーズ

すべてのテストケースが合格し、承認が得られたら `n8n-deploy` へ進む。

# UIデモ（統合版 v2）

開き方：このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開く（`data/` を読み込むため、ファイルを直接開くと動きません）。

## 取り込んだもの
- 共有デモ（claude.ai/artifact/TrxKQeMK3yHyE7APPPnAvg）から：収録弾294件・カード13,481枚のカード情報（`data/sets.json`、`data/cards.json`）、収録弾の棚（拡張パック／デッキ・BOX／プロモ／基本エネルギー）、収録弾ページ（レアリティ絞り込み・価格下限・列の並べ替え・さらに表示）、検索候補、ダークモード。
- 初回デモから：ポケカ買取指数、上昇・下落ランキング、90日ぶりの高値・安値、算出店数と「通常／更新待ち／データ不足」の3状態、店による価格差、マイコレクション（端末内保存）、配色切替、新商品・公式情報の枠、算出方法の説明、非公式サイト表記。

## 価格は全部ダミー
- `data/cards.json` の6列目（base）は、共有デモにあった価格を「ダミー生成の目安」として残したもの。**実際の平均買取価格ではありません。**
- 前日比・店数・チャート・指数はカードIDから決まるダミーです（画面上部にも明記）。
- 共有デモの価格は、収録弾の数（294）などから**1店分のデータとみられます**（未確認）。仕様は「2店以上の平均・店数を表示」なので、そのまま平均としては出していません。
- カード画像は使っていません（文字とレアリティの枠のみ）。

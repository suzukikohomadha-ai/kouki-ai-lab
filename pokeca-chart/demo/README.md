# UIデモ（統合版 v3：監査指摘の修正版）

開き方：このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/` を開く（`data/` を読み込むため、ファイルを直接開くと動きません）。

## データ
- `data/sets.json`（294件。うち掲載カードがあるのは287件）、`data/cards.json`（13,481枚：[id, 収録弾slug, レアリティ, 型番, カード名]）。
- 出所：共有デモ（claude.ai/artifact/TrxKQeMK3yHyE7APPPnAvg）。社長の回答（2026-10-09）では、claude.ai のチャットで Claude がプログラムにより遊々亭の買取ページを自動取得して作成したもの。M6a の8枚で価格が遊々亭の表示価格と一致（引き継ぎ資料 付録A）。取得時の間隔・User-Agent・robots.txt 確認の有無は未確認。収録弾の全カードではない。
- 公式情報との照合はサンプルのみ（2026-10-09、リサ）。MEGA期の商品名8件とカード6枚は一致。M6a FUR の型番 134/103・135/103 は公式で未確認。
- 監査で見つかったシリーズ分類の誤りを修正：sc・szd・mdb → BW、snprb・snpnb → XY。
- 型番の欠け表記（空文字と「-」）は空文字にそろえ、画面では「型番なし」と表示。
- 共有デモにあった価格の列と「100円以上の枚数」は削除した（1店分とみられる実価格のため）。

## ダミーのもの
価格・前日比・店数・価格差・強化買取・チャート・指数・ランキング・順位・枚数の集計・評価額・更新日時・シリーズ別の対応予定。ダミー価格はカードIDとレアリティから生成しており、実在の価格とは連動しない。

## 未対応（要判断）
- レアリティの独自表記（TD、S-TD、-）と「PR」「PROMO」の混在。
- 同名の収録弾（sccha と sccha2）、同じ収録弾内の型番・名前の重複（例：sh の 014/053）。
- シリーズ別の対応予定の時代区分（「旧裏面」がどこまでを指すか等）は未確認。
- 外部公開前：商標表記、サイト名の「ポケカ」、元データの出所の確認（リョウ・社長）。

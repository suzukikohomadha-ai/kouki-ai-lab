## 一言でいうと

**「物流会社KPMの中で、今は人がバラバラに管理している出荷業務の情報を、AIが自動でつなげて把握し、問題が起きたら人に判断を仰ぎながら先回りで動く仕組み」**を提案する資料です。

新しいツールを1つ追加するのではなく、KPMが既に持っている業務（海上輸送・陸送・契約・見積り等）の「上に乗って全体をつなぐ層」を作る、というのがコンセプトです。

## そもそもの課題

ブラジルの食品輸出業者が「冷凍食品をブラジルからアメリカへ送りたい」と依頼してきたとします。この1件の出荷のために、KPM社内では、

見積り担当 → 契約担当 → 貨物担当 → 陸送担当 → 港湾担当 → 海上輸送担当 → 通関担当 → 配送担当 → 顧客対応担当

と、実にたくさんの人が別々に関わります。今はこれを人がバラバラに調整しています。

## 提案されている仕組み（9つのAI担当者）

資料では、この一連の流れを9つの役割（エージェント）に分けて、AIに担当させることを提案しています。人間の会社に例えると分かりやすいです。

| # | AIの役割 | 人間で例えると |
|---|---|---|
| ① | 受付エージェント | 電話・問い合わせを受けて要件を聞き取る受付係 |
| ② | 貨物担当エージェント | 「これは何の荷物か」を見分ける倉庫の専門家 |
| ③ | 契約エージェント | 契約書を読んで条件を確認する事務担当 |
| ④ | ルート担当エージェント | 「どう運ぶのが一番いいか」を考える配車・航路の専門家 |
| ⑤ | 車両・キャリア担当エージェント | トラックや運送業者の空き状況を管理する配車係 |
| ⑥ | 出荷モニタリングエージェント | 「船が予定通り出たか」を常に見張っている監視担当 |
| ⑦ | 例外対応エージェント | トラブルが起きたときに真っ先に動く緊急対応担当 |
| ⑧ | 顧客対応エージェント | 「今どこにありますか？」に答えるカスタマーサポート |
| ⑨ | 社内アシスタントエージェント | 上司（ジーン氏）に「今どの案件が危ないか」を報告する秘書 |

そして、これら9人（9つのエージェント）をまとめて指揮する**「オーケストレーター」**（＝交通整理をする管制官）が全体の司令塔になります。

## 一番のポイント：「自動化」と何が違うのか

これは資料の中でも強調されている、一番大事な部分です。

- **単なる自動化**：「遅延が起きたら → メールを送る」のように、決まった1つの反応をするだけ
- **AIオーケストレーション**：「遅延を検知する → それが顧客の納期に影響するか考える → 影響するなら代替案を考える → 人に確認を取る → 実行する → 顧客に連絡する」というように、**状況を理解して、複数の作業をつなげて動く**

つまり「反射的に動く」のではなく「考えてから、必要な範囲で動く」仕組みだ、という違いです。

## もう一つの重要なポイント：AIに全部任せない

資料は繰り返し、**「重要な判断はAIだけで決めさせず、必ず人間の承認を挟む」**と念押ししています。

流れとしては：

**AIが「こうしたらどうですか」と提案する → 人間が「それでいこう」と承認する → システムが実行する**

これは物流のように、判断ミスが顧客への実害（納期遅れ・追加コスト）に直結する業界では、特に重要な設計思想です。

## 既存事業を置き換えない、という位置づけ

この提案は「KPMの海上輸送・陸送・保険といった既存の事業をAIに置き換える」という話ではありません。それぞれの事業の**間をつなぐ「上乗せの層」**として、可視化や調整を担当させる、という位置づけです。

## 最初の一歩として提案されているもの（MVP）

いきなり9つ全部を作るのではなく、**「出荷モニタリング＆例外対応」の1つだけ**からスタートすることが提案されています。理由は、これが一番分かりやすく効果を測定しやすいからです。

具体的には：
1. 出荷データを受け取る
2. 状況を見張る
3. 予定とのズレを検知する
4. 影響を受ける案件を特定する
5. 担当者に知らせる
6. 次にどうすべきか提案する
7. 顧客への連絡文を用意する

これを導入する前と後で「対応にかかった時間」「遅延に気づくまでの早さ」などを比較して、効果があれば次の機能（車両管理・契約管理…）へ広げていく、という段階的な進め方です。

## ジーン氏への伝え方（資料が提案する売り込み方）

資料は「AIエージェントを9個作ります」と機能を並べて売り込むのではなく、**「今は人が情報をつなげているが、これからはAIが情報と業務の流れをつなげ、人は重要な判断だけに集中できるようになる」**という、ビジネスの変化として伝えることを勧めています。

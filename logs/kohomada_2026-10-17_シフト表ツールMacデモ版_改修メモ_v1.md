## 1. 直したところ（原因調査 v2 の見立てに対応）

| 原因 | 直し方 | 影響する操作 |
|---|---|---|
| ActiveX のボタン 14個（Mac では押せない） | 図形のボタン（マクロの登録）に置き換えた。位置・文言は元のまま。新しい標準モジュール modMac から元と同じ手続きを呼ぶ | ① CSV取込、② シフト表作成、フロコン表作成・一括作成、セル結合・結合解除・リセット（ホビトレ・アパ家）、タスク更新、チェックリストの一覧表示、ハイソル備考の表示・非表示 |
| Scripting.Dictionary（Mac に無い） | 同じ動きのクラス MacDict を足した。modCommon.NewDict が、Windows では Scripting.Dictionary を、Mac では MacDict を返す | ほぼ全部（設定の読み込み・割当・日付の切り替え・印刷など） |
| VBScript.RegExp（取り込み時に「番_」以降を消す処理） | Mac では「番_」の位置で文字を切る | ② シフト表作成 |
| Scripting.FileSystemObject（CSV の写し） | Mac では FileCopy で写す | ① CSV取込 |
| パスの区切り「\」の決め打ち | Mac ではバックアップ・CSV の写し・PDF の場所を「/」で作る | ①・②・前の月の写しを消す・1週間分を出す |
| Environ・WScript.Shell・GetOpenFilename の絞り込み | Mac では使わない。CSV は種類を絞らずに選び、名前が .csv かをあとで確かめる | ① CSV取込、PDF の置き場所選び |
| Mac のサンドボックス（ファイルの読み書きに許可が要る） | Mac でバックアップを保存できないときは、「バックアップなしで続けるか」を聞く（既定は「いいえ」） | ①・②・前の月の写しを消す |

- Windows での動きは変えていない。Mac 用の処理は `#If Mac Then` の中にだけ書いた。ただし、ボタンは図形に替えたので、Windows でも図形のボタンから同じ処理が動く。
- 触っていないもの：旧版の「フロコン(BO)」シートの ActiveX ボタン3個。案内資料で「触らなくて大丈夫」としているシートなので、そのままにした。

## 2. 作り方（記録）

1. xlsm の VBA プロジェクトから、全モジュールのソースを取り出した。
2. ソースを直し、新しいモジュール2つ（MacDict・modMac）を足した。
3. VBA プロジェクトを作り直した。
   - コンパイル済みのキャッシュ（P-code）を外し、ソースだけを持つ形にした。
   - バージョン値は 0xFFFF にした（MS-OVBA の仕様に沿った書き方）。
   - そのため、Excel は開いたときにソースからコンパイルし直す。
4. ActiveX のボタンと、その絵（VML）の部品を消し、図形のボタンを足して xlsm に詰め直した。
5. 確かめたこと（いずれも Linux 上で確認。Excel では未確認）：
   - zip の整合と、参照切れがないこと
   - openpyxl で開けること
   - LibreOffice で開いて PDF にできること。図形のボタンが元の位置に出ていた
   - olevba で 34 モジュールを読めること

## 3. Mac での確認リスト（社内の Mac で実施）

前提：ファイルは「書類」などパソコンの中のフォルダに置く。OneDrive やデスクトップの同期フォルダには置かない。

1. [ ] ファイルを開く。「マクロを有効にする」を押す。エラーが出ないこと
2. [ ] Excel のメニュー「ツール」→「Visual Basic Editor」→「デバッグ」→「VBAProject のコンパイル」で、エラーが出ないこと（いちばん大事）
3. [ ] スタッフ一覧で「① CSV取込」→ CSV を選ぶ
   - ファイルの使用の許可を聞かれたら「許可」を押す
   - 取り込みが終わること
   - 「バックアップ」フォルダに控えができること
4. [ ] 未割当の人が出たら、帯を選んで「未割当の人を移す」を押す
5. [ ] 「② シフト表作成」→ 売場シートとフロコン表ができること
6. [ ] フロコン表で、左上の日付を ▼ から切り替えられること
7. [ ] フロコン(ホビトレ)・(アパ家)で、セル結合・結合解除・リセットが効くこと
8. [ ] 売場シートで、「表示する週」の切り替えと「フロコン表 一括作成」が効くこと
9. [ ] 目次の「1週間分を出す」で、印刷と PDF の両方を試す（PDF はフォルダ選びの画面が出るか、同じフォルダに置くかを聞かれる）
10. [ ] 保存して閉じ、開き直しても内容が残っていること

うまくいかなかったときは、エラーのメッセージと、何番の手順で起きたかを控えてください。

## 4. 残る不確実性

- Mac の Excel のバージョンによって、次の動きが変わる可能性がある。
  - ファイル選び・フォルダ選びの画面（GetOpenFilename・FileDialog）
  - ファイルの使用の許可の出方
- CSV の文字コード（Shift-JIS か UTF-8 か）によっては、Mac で開いたときに文字化けする可能性がある［要確認］。
- ソースからコンパイルし直す方式なので、初回に開くと少し時間がかかる可能性がある。

# 波・風・太陽を一つの浮体で
# NoviOcean「Medi Wave 850H」日本語概要資料

## 1. NoviOceanとMedi Wave 850H

**NoviOcean AB**は、スウェーデンの海洋エネルギー企業です。同社によると、2016年からハイブリッド型の洋上エネルギーの開発に取り組んでいます。同社は自らを「システムインテグレーター」と位置づけ、独自の波力発電の仕組みに、専門メーカーの発電技術を組み合わせて一つのシステムにまとめる会社だと説明しています。

**Medi Wave 850H**は、海に浮かぶ一つの台（浮体）の上に、3種類の発電設備を載せる設計です（以下、同社の説明による）。

| 発電 | 仕組み（同社の説明） |
|---|---|
| 波 | 浮体の側面のフロートが波を受けて動き、油圧シリンダーを駆動。その圧力でペルトン水車と発電機を回す。水中に歯車箱や発電機を置かない設計 |
| 風 | 浮体の上に垂直軸型の風車を並べる設計（Wind Harvest社の技術を採用） |
| 太陽 | デッキに、軽くて曲げられるCIGS太陽電池（薄膜型の太陽電池の一種）を敷く設計（Midsummer社の技術を採用） |

- **定格出力**：1基あたり合計850kW（**同社の推定値**）
- **年間発電量**：1基あたり約2,500MWh（**同社の試算**。代表的な試算値で、特定の場所の予測ではありません。実際の発電量は設置場所によって変わります）
- 同社は、海上での統合と最終的な構成には、今後の設計と検証が必要だと説明しています。

## 2. 現在の開発段階

【図の挿入位置：logs/kohomada_2026-10-14_NoviOcean紹介note_開発段階図_v1.png】
キャプション：「NoviOceanの開発段階（同社の公開情報をもとに株式会社コホマダ作成）」

- 現在は**段階4：デモ機「NO3」（波・風・太陽）を海上で試験中**です（2026年）。NO3は、装置の波の中での動きやシミュレーションの精度を確かめるためのもので、発電系そのものの検証は対象外とされています。
- 同社は、NO3が商業発電を行う設備ではないこと、そして**実機サイズの装置は現時点で海上では稼働していない**ことを明記しています。
- 次の段階5は、電力会社をパートナーとして行う計画の**実機サイズの初号パイロット**で、同社の見込みは**2027〜2028年**です。
- **時期は変わりえます。** 同社は2026年7月の別の発表で、初号の商用パイロットの目標を2026〜2027年としています。開発の時期は、これまでにも変わってきています。
- 日本での導入例は、公開情報では確認できていません。日本での導入の予定や時期は決まっていません。

## 3. 想定される用途

同社は、優先する用途として次の4つを挙げています（全体では約12の用途を挙げています）。

1. **離島・沿岸地域**：燃料代に加え、運搬・取り扱い・貯蔵の費用がかかるディーゼル発電への依存を課題として挙げています
2. **沿岸データセンター**：電力需要の伸びに、陸上の送電網への接続整備が追いついていないという課題を挙げています
3. **海水淡水化**：なお同社は、同じエネルギーを電気として使うか造水に使うかは二者択一で、両方を足し合わせることはできないと説明しています
4. **養殖**：海の養殖場は電力網がない、または弱い場所にあることが多く、ディーゼル燃料に頼りがちだと説明しています

## 4. 日本で検討する際の確認事項

- **海域の条件**：同社は、通常運転を波高0.5〜5mで想定しています（同社の設計目標値）。設置水深は20〜200mとしています（同社シミュレーターページの記載）。候補地ごとに、波や水深などのデータで個別に評価する必要があります。
- **制度**：いわゆる再エネ海域利用法（2026年4月1日施行の改正後の題名は「海洋再生可能エネルギー発電設備の整備に関する法律」）は、対象となるエネルギー源を施行令で「海域における風力」と定めており、波力や太陽光は含まれていません。一体型の設備が同法の仕組みの中でどう扱われるかは、確認できていません。海域の占用の手続き、漁業関係者との調整、電気事業法等の扱いも、候補地ごとに確認が必要です。
- **費用**：本体価格・導入費用は公表されていません。費用は設置条件等により異なるため、個別のご相談となります。

2. **キット（note有料記事）のMVP推奨価格（検証用・仮価格）**：**¥9,800**（単発）。競合`ai_app_pro`氏の買い切り価格帯（9,800〜19,800円）の下限に合わせ、対象業種が1業種（貿易・海外展開支援）に絞られている分、下限アンカーから始める設計。根拠は分析2節。
3. **損益分岐点（例示計算）**：月次固定費の想定シナリオ（標準・保守的・楽観的）に対し、上記価格・想定契約者構成（低価格帯ほど多い"じょうご型"）で試算すると、**標準シナリオで月間合計約25件（内訳目安：第1階層13件・第2階層8件・第3階層4〜5件）の契約があれば固定費を回収できる**という計算例になります（分析3節）。**これは実データではなく計算方法を示すための例示**であり、MVP初期の実際の契約数がこれに届かなくても失敗ではありません。
4. **MVP運用方針**：定期購読を本命価格でいきなり開始せず、まず**個別声かけ（クローズドβ）でモニター価格を提示し、単発決済または簡易な形で反応を検証してから、正式な月額サブスク商品（note）を作る**ことを推奨します。理由は、noteの定期購読マガジンは**公開後に価格変更ができない**という確定済みの制約があり、価格を決め打ちして本番商品化する前に反応を見る必要があるためです（分析4節）。
5. **リスク**：価格を高くしすぎるとモニター応募が集まらず検証自体が始まらないリスク、低くしすぎると（特に定期購読マガジンでは）後から値上げできず採算が固定化されるリスクの両方があります（リスク・注意点参照）。

## 推測・仮説

- ［仮定］3階層をnoteの「メンバーシップ」機能で実装できれば、手数料は「定期購読マガジン」より有利（10%＋決済手数料5〜15%＝合計15〜25%）になる可能性が高い。ただし価格変更可否・プレミアム加入要否が未確認のため、本メモの損益分岐点試算は**保守的に「定期購読マガジン相当の固定費（プレミアム500円＋振込270円）」を含めて計算**している。メンバーシップで実装でき、かつプレミアム加入が不要と判明すれば、月次固定費は本メモの試算よりやや軽くなる方向に動く。
- ［仮定］第3階層の個別サポート工数は、契約者数が少ないMVP初期段階では1人あたり月数十分〜1時間程度と想定し、月間合計5〜10時間程度と仮置きした（分析3節の標準シナリオ）。実際の工数は契約者の質問頻度・カスタマイズ要望の深さに強く依存するため、実データで再確認が必要。
- ［仮定］MVP初期の契約者構成は、価格が低い階層ほど人数が多い「じょうご型」（例：第1階層：第2階層：第3階層＝おおむね5:3:2）になると仮定した。実際の比率はT61のモニター打診結果次第で変わりうる。

### 2. キット（note有料記事）のMVP推奨価格

| 項目 | 内容 |
|---|---|
| 商品形態 | note**単発**有料記事（プラットフォーム利用料10%＋決済手数料5〜15%、合計約15〜25%） |
| 対象 | 第3階層（伴走プラン）の3ヶ月以上継続契約者限定 |
| MVP推奨価格 | **¥9,800** |
| 妥当と考えられる価格帯 | ¥6,800〜14,800程度（下記根拠のレンジ） |

**根拠**：

1. **競合比較**：`ai_app_pro`氏は7業種分のテンプレート一式を9,800〜19,800円（買い切り）で販売している。今回のキットは1業種（貿易・海外展開支援）に絞られているため、7業種パッケージの下限（9,800円）と同水準からの開始が、対象範囲の狭さと釣り合いが取れると考えられる。
2. **顧客属性の違い**：`ai_app_pro`氏の買い手は不特定多数の一般顧客だが、今回のキット購入者は**既に月¥9,800を3ヶ月以上支払い続けている、既に信頼関係が構築された顧客に限定**されている。一般公開の買い切り商品より価格への抵抗が小さい可能性がある一方、この購買層特性そのものが未検証であるため、下限（9,800円）からの開始が無難。
3. **「実務者が実際に使っている運用資産一式」という価値**：チェックリストや解説記事（300〜980円帯）とは商品の性質が根本的に異なり、既存の低単価帯を参照基準にすることは適切ではない。
4. **手取り**：note単発記事の手数料（10%＋5〜15%）は、定期購読マガジンより有利（合計約15〜25%）。¥9,800の場合、手取りは約¥7,350〜8,330程度（決済手段による）。

**キット単体の採算の考え方（一時的な制作・保守コストの回収）**：キットは月次の固定費というより、①初回制作工数、②Claude Code仕様変更への追従保守工数、という性質のコストを持つ。仮に初回制作＋直近の保守に要する工数を20時間、時間単価を例示の¥3,000/hとすると、一時コストは約¥60,000。¥9,800（手取り約¥8,000として計算）であれば、**約8件の販売で当該コストを回収できる計算**（あくまで計算方法の例示であり、実際の制作時間・時間単価は未確認）。

### 4. MVP検証段階での価格運用方針

T61（レン）は、貿易・海外展開支援MVPについて「無料または低価格の『モニター提供』フェーズを設け、成功・撤退の判断基準を事前に定義してから正式価格へ移行する」方針を既に示している。この方針と、note定期購読マガジンの「公開後に価格変更不可」という確定済みの制約を踏まえ、以下の段階的な進め方を推奨する。

**推奨する進め方（2段階）**：

1. **第1段階（フェーズ1・現在）：個別声かけによるクローズドβ＋モニター価格**
   - note上に本番のサブスク商品（定期購読マガジン／メンバーシップ）をまだ作らず、既存note読者・過去の貿易相談実績のある顧客に個別のDM・メール等で打診する（T61の推奨と同じ）。
   - 決済は、note単発記事（価格変更可能）または簡易な個別対応（請求書等、社長ご自身の判断）を用い、**正式な定期購読・メンバーシップ商品としてはまだ確定しない**。
   - モニター価格の例（検証用・仮価格、正式価格からおおむね半額程度を目安）：

     | 階層 | 正式MVP価格（本メモの提案） | モニター価格（例示） |
     |---|---|---|
     | 第1階層 | ¥980/月 | ¥500/月 |
     | 第2階層 | ¥2,980/月 | ¥1,500/月 |
     | 第3階層 | ¥9,800/月 | ¥4,900/月 |
     | キット | ¥9,800 | モニター先着特典として¥4,900、または継続モニターへの謝礼として提供（無償にするかどうかは社長判断） |

   - モニター価格を「半額」とするか「無料」とするかは、T61の「無料または低価格」という既存方針の範囲内で社長が選べる。無料にする場合は、後述のリスク（値付けの説得力を後から出しにくくなる）に留意する。

2. **第2段階：モニターの反応を見て、本メモが提案する正式MVP価格（¥980／¥2,980／¥9,800、キット¥9,800）でnote上に正式なサブスク商品を立ち上げる。**
   - この段階で初めて、価格変更が困難な定期購読マガジン（またはメンバーシップ）を実際に公開する。
   - 立ち上げ前に、note「メンバーシップ」の価格変更可否・プレミアム加入要否を必ず確認する（確認済み事実の[未確認]参照）。

この2段階を踏むことで、「値付けを間違えたまま変更できない商品を最初から本番公開してしまう」リスクを避けられる。

## リスク・注意点

1. **初期価格を高く設定しすぎるリスク**：特に第3階層（¥9,800/月）は競合の買い切り価格の下限と同水準であり、「買い切りではなく継続課金」という点への心理的抵抗から、モニター応募自体が集まらない可能性がある。モニター価格（¥4,900等）での提示・無料モニターの検討余地を残すことでこのリスクを緩和する。
2. **初期価格を低く設定しすぎるリスク**：特にnote定期購読マガジンは公開後に価格変更ができないため、正式価格を安く始めてしまうと、後から値上げする手段が「新マガジンの作成＋旧マガジンの終了」しかなく、既存購読者の離脱・評判リスクを伴う（`kohomada_2026-07-28_note収益化_価格設定手取り試算_v1.md`確定事項）。第1段階（クローズドβ・モニター価格）を経てから正式価格を確定する2段階方式を推奨する理由はこのリスク回避のためでもある。
3. **note商品形態が未確定であること**：メンバーシップ（10%手数料）と定期購読マガジン（20%手数料）のどちらで実装するかにより、手取り額・損益分岐点が大きく変わる。実装前の確認を強く推奨する（確認済み事実参照）。
4. **保守工数・時間単価が未確定であること**：本メモの損益分岐点試算は、T59から引き続き「実在の時給相場を断定しない」立場を取っており、¥3,000/hはあくまで計算方法を示す例示。鈴木さんご自身の実際の工数感（特に第3階層の個別サポートに要する時間）が分かり次第、再試算が必要。
5. **第3階層の「take-and-run」リスク**：T85が既に指摘するとおり、3ヶ月継続後にキットだけ受け取って解約する顧客が一定数出る可能性がある。本メモの損益分岐点試算はキット販売による追加収益を含めていないため、この点は保守的な試算になっている。
6. **法務論点が未解決のまま高額課金を本格化させないこと**：事業計画書6節・T61が指摘するとおり、Anthropic規約解釈・特定商取引法上の返品条項等のレベル3論点は、MVP検証後・本格展開判断時に実弁護士確認を行う方針。本メモの価格試算はこの前提（MVP段階＝低リスクの検証的販売）の範囲内で位置づけるべきであり、価格が固まったことをもって法務論点が解決したと解釈しないこと。

# 有料コンテンツ素材：AI・DX導入プロセスチェックリスト（メイ）

- 基準日：2026-07-28
- 位置付け：有料記事／チェックリスト素材の下書き（Draft）
- 前提：一般的なAI/DX導入プロジェクトの標準フェーズを整理したもの。特定ベンダー・特定製品名は挙げず、汎用的な意思決定チェックリストとする。

## フェーズ1：要件定義

- [ ] 解決したい業務課題を1文で言語化できているか（「なんとなく自動化したい」で止まっていないか）
- [ ] 対象業務の現状フロー（As-Is）を書き出したか
- [ ] 「人がやるべき部分」と「自動化してよい部分」を切り分けたか（全自動化を最初から狙わない）
- [ ] 成功の定義（KPI）を数値で置けているか（例：月間工数◯時間削減、対応時間◯分短縮等）

## フェーズ2：ベンダー・ツール選定

- [ ] 候補ツール・ベンダーを複数比較したか（1社に飛びつかない）
- [ ] 初期費用・月額費用・従量課金の有無を確認したか
- [ ] データの保存場所・第三者提供の有無（プライバシーポリシー）を確認したか
- [ ] 自社の既存システム（会計・顧客管理等）との連携可否を確認したか
- [ ] 解約条件・データのエクスポート可否（ベンダーロックインのリスク）を確認したか

## フェーズ3：導入

- [ ] 小さく試す範囲（PoC・一部業務での試験導入）を決めたか
- [ ] 導入時に必要な社内の役割分担（誰が設定・誰が承認・誰が最終責任者か）を決めたか
- [ ] 外部に送信してはいけない情報（個人情報・機密情報）の線引きを事前に決めたか
- [ ] 想定外の誤動作・エラー時の切り戻し手順を用意したか

## フェーズ4：運用・改善

- [ ] KPIを定期的に確認する仕組み（月次レビュー等）があるか
- [ ] 現場からのフィードバックを吸い上げる窓口があるか
- [ ] 継続的な費用対効果（ROI）を見直すタイミングを決めているか
- [ ] 属人化していないか（担当者が変わっても運用が止まらない体制か）

## リスク・注意点

- 「このチェックリストを満たせば必ず導入が成功する」という断定はしない。あくまで見落としを減らすための一般的な観点整理として提示する。
- 特定の製品・ベンダー名を挙げると、実績のない推奨に見えるリスクがあるため、本テンプレでは避けている。

## 次に必要なアクション

- カエデへ、チェックボックス付きPDF等の体裁制作を依頼するか検討

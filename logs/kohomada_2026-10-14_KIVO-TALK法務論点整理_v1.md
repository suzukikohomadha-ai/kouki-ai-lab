## 結論

1. **ステマ告示の名宛人は原則KIVO社**（景表法第5条「自己の供給する商品又は役務」、Q&A Q1）。コホマダの記事が問題になるのは「KIVO社の表示」とみなされる場合。ただし信用面・note規約面のリスクはコホマダに残る。
2. **招待特典のみの自発的紹介の評価は分かれ得る**。「当たらない」方向：運用基準 第2-2(1)ウ（やり取り一切なしのアフィリエイト）・カ（キャンペーンへの自主応募）。「当たる」方向：対価は経済上の利益一切を含む（第2-1(2)イ注）、登録1件ごとのポイントは成功報酬に類似。[要弁護士確認]
3. **既存の質問No.8（強調してほしい点・控えてほしい表現）は送らない**。KIVO社が表示内容の決定に関与したと評価される方向に働くおそれ。
4. 法的義務の有無にかかわらず、**冒頭・CTA付近・末尾の3か所に、本文と同じ大きさで開示**を入れることを推奨（末尾のみ・小さい文字は運用基準上「不明瞭」の例）。
5. **ベーシックプランの招待リンクは1人しか使えない**（https://www.kivo.talk/subscription ）。サブスク（月500円）なら何人でも可。記事掲載前にプランの確認が必要。
6. noteの規約は未確認。KIVO社のブランドガイドラインにスクリーンショットの定めはない。

**推測**：KIVO社とのやり取りがなく、全ユーザー共通キャンペーンへの自発的参加だけなら「KIVO社の表示」と評価される可能性は相対的に低い。ただし、記事の主目的が招待獲得と見える場合は逆方向の評価もあり得る。KIVO社に記事の論点・表現を相談する、下書きを確認してもらう、代理店になる、個別報酬を受けると、関与の評価に大きく動く。

### 論点2：記事表現のリスク
- 「唯一」：公式比較ページに根拠データなし [確認済み事実]（https://www.kivo.talk/compare ）
- 「完全に保護」「流出しない」：規約第28条に保護・流出の保証なし [確認済み事実]。限界を書かないと優良に見せるおそれ [推測]
- 他社比較（note・Discord等）の転載：他社の信用・noteとの関係に関わる。不正競争防止法等の評価は [未確認]・[要弁護士確認]
- 「登録すると1,000pt」は誤り（付与されるのは招待した側と読める）。換金性・終了日は未確認
- ベーシックプランのリンクで「誰でも登録できます」と書くと誤認させる

### 論点3：18歳以上限定サービス
- [推奨対応] タイトル直下とCTA直前に「18歳以上限定」を明記。10代・学生向けの訴求をしない。R18機能を目玉にしない。R18コンテンツや人物写真が映る画面を使わない
- 青少年保護関係法令・noteの年齢ポリシー：[未確認]・[要弁護士確認]

### 論点4：noteの規約
- note利用規約・ヘルプは403で取得できず [未確認]。社長か担当者がブラウザで原文と更新日を確認する
- KIVO規約第19条1項13号10はアプリ内での宣伝・営業を禁止。アプリ内から記事へ誘導する場合は抵触の可能性を要確認

### 論点5：ロゴ・スクリーンショット
- ロゴ：ブランドガイドライン（https://www.kivo.talk/brand ）の禁止事項・最小サイズ・クリアスペースを守る。許諾窓口 cs@kivo.talk。事前許諾を推奨

## ③ 記事で使ってはいけない表現

| 表現 | 理由 |
|---|---|
| 「唯一の」「業界初」「No.1」「最も安全」 | 根拠データなし |
| 「完全に保護」「絶対に流出しない」「100%守られる」 | 規約に保証なし・限界あり |
| 「登録すると1,000ポイント」「1,000円分無料」 | 付与対象・換金性が違う／未確認 |
| 「手数料が安い」「稼げる」「月◯万円」 | 手数料率非公開 |
| 「noteより安全」等の他社比較 | 根拠不十分・他社の信用 |
| 「誰でも」「学生さんも」「10代に人気」 | 18歳以上限定 |
| 「R18もOK」「大人向けが充実」 | 規約との関係未確認・ブランドリスク |
| 「公式推奨」「KIVO公認」 | 許諾・提携の事実なし |
| 「中立な第三者レビュー」（開示と併用） | 運用基準 第3-1(2)イの矛盾例に近い |
| 「今だけ」「期間限定」 | 終了日未確認 |

## 代替案
- A：招待リンクを載せず、公式ダウンロードページ（https://www.kivo.talk/download ）のみ。特典の問題がほぼなくなるが、読者はゲストモード（閲覧のみ）止まり

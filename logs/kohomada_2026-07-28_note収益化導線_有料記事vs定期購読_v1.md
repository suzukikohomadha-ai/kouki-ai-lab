# note収益化：有料記事 vs 定期購読マガジン 両論併記（サトル）

- 基準日：2026-07-28
- 対象：note.com/kohomadha（貿易・海外展開マガジン／AI・DX導入マガジン）
- 前提：[[kohomada_2026-07-28_note収益化制度調査_v1.md]]（T34・リサ）を踏まえる。手数料率は[未確認]のため、価格帯は暫定。

## 結論

「両論併記」の指示を踏まえ、有料記事単発・定期購読マガジンの2モデルを比較する。どちらか一方に決め打ちせず、**定期購読マガジンを軸にしつつ反響の高い記事を単発でも切り出す併用型**を叩き台として提案するが、最終選択は鈴木さんの判断事項とする。

## モデルA：有料記事単発

- **概要**：記事の冒頭を無料公開し、続きを有料化。都度課金。
- **適合パターン**：スポット性の高い専門ノウハウ（特定国の輸出入規制まとめ、展示会出展レポート、AI導入の個別事例など）。
- **ファネル（認知→興味→比較検討→行動）**：無料記事でnoteフォロー獲得 → 有料記事のCTA（具体的な成果・数字を一部見せる「ちら見せ」）→ 購入。
- **KPI階層**：北極星＝有料記事の月間売上。中間指標＝無料記事フォロー転換率・有料記事CTAクリック率。施策指標＝各記事のPV・購入件数。
- **メリット**：初期ハードルが低い（単発課金）、記事単体の価値証明がしやすい。
- **デメリット**：都度の集客努力が必要、LTVが伸びにくい。

## モデルB：定期購読マガジン（サブスク）

- **概要**：月額課金で継続的にコンテンツを提供。
- **適合パターン**：継続的な情報ニーズを持つ読者（輸出入担当者・AI導入検討中の経営者等）。**既存の週次note自動化ルーティン（貿易・AI/DXマガジンの隔週下書き）との親和性が高い**。
- **ファネル**：無料記事 → 公式LINE等での中間接点 → 体験号・初月割引 → 定期購読。
- **KPI階層**：北極星＝MRR（月間経常収益）。中間指標＝登録者数・解約率（チャーン）・LTV。施策指標＝無料→有料の転換率。
- **メリット**：収益の予測可能性が高い、既存の週次運用資産をそのまま単価化できる。
- **デメリット**：手数料率が単発より高いという言及がある（[未確認]）。継続コンテンツを切らさない運用負荷が発生し、質が落ちると即解約に直結する。

## 両論併記としての叩き台の提案 [仮定]

併用型：**定期購読マガジンを軸**（週次自動化ルーティンの資産をそのまま活用できるため運用負荷が小さい）にしつつ、**特に反響の高かった無料記事は単発でも切り出し販売**する二段構え。単発の低LTVと、定期購読の立ち上がりの遅さを互いに補う狙い。ただし需要の見立ては仮説段階であり、実際にどちらが読者に刺さるかはローンチ後のデータで検証が必要 [仮定]。

## 価格帯（暫定・[仮定]）

- 定期購読：月額500〜980円程度を暫定レンジとして提示。ミナの手取り試算（T37・手数料率確定後）と、貿易/AI・DX系の他クリエイターの価格帯調査（要リサ追加調査）で精緻化する。
- 単発記事：300〜500円程度を暫定レンジとして提示。

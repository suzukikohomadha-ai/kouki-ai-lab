## エグゼクティブサマリー

- **直接競合は買い切り型のみ**。`ai_app_pro`氏（AI社員16名×業種別テンプレ7種、9,800〜19,800円）・`u_suke_37`氏（Claude Code×note量産術）がnote/Brainで確認済み。いずれも「教える専門家」ポジションからの単発ファイル販売。
- **サブスク（継続課金）型でClaude Code／AIエージェントパッケージを販売する直接競合は、2回の調査（T60・T84）を通じて確認できなかった。** ただし「確認できない＝存在しない」ではなく、検索言語・検索深度の限界によるもの。
- 階層型サブスク自体（Basic/Standard/Premium等）は、note・Discord・Udemy・SaaS業界全般で確立された「よくある型」であり、独自性の主張材料にはならない。差別化軸は業界共通で「コンテンツ量」「個別サポート」「テンプレート・ファイルの有無」「コミュニティアクセス」「対応速度」の5系統に整理できる。
- 「3ヶ月以上継続で特典を出す」設計も、コーヒー定期便・語学スクール・携帯キャリア等で広く使われる定石であり、目新しさはない。
- **コホマダの差別化の核は「実務者発の信頼性」（案C）であり、競合の「教える専門家」ポジションとは明確に異なる。** 一方「エージェントとUIの着せ替え」（案A）は、先行事例が見つからないことが「差別化になり得る」根拠であると同時に「まだ誰も価値を証明していない」根拠でもある、という両義性を持つ。

### 2.3 間接競合・近縁事例

- **LUVO**（オルツ×キャスター、AI社員派遣＋オリジナルキャラクター制作、法人向け、価格非公開）

- GPT Store・Dify・Zapier/Make（業種別テンプレート配布。多くは無料または機能紹介の域）

### 2.4 業界共通の階層設計パターン（5系統）

note メンバーシップ・Discordサーバーサブスク・SaaS業界（Zenskar/Chargebee解説記事、Airtable・Zoho CRM等の実例）・Udemy Businessいずれも、以下の5系統の組み合わせで階層を差別化している。

1. **コンテンツの量・深さ**
2. **個別サポートの有無**（メール→チャット→電話→専任担当者と段階的にエスカレーション）
3. **テンプレート・ファイルの有無**
4. **コミュニティ・交流機能へのアクセス**
5. **対応速度・SLA**

Udemy Businessは特に参考になる実例で、Personal Plan（月$20）→Team Plan（年$360/人、コース数・分析機能・24時間サポート）→Enterprise Plan（21名以上、専任カスタマーサクセス）という3階層構成であり、コホマダの「スタータープラン→実務プラン→伴走プラン」（T85）と、コンテンツ量→サポート専任度で差をつける発想が一致する。

## 3.「3ヶ月継続でキット配布」設計の分析

### 3.1 他業界での類似事例

| 業界 | 設計 |
|---|---|
| コーヒー定期便 | 6回目以降5%引き、12回目以降10%引きという回数連動型割引 |
| ゴディバ | 12ヶ月継続で継続カウントリセット＋オンラインショップ限定クーポン |
| 資生堂 | 配送回数（1回目・4回目等）に応じたサンプル・ディスペンサー追加 |
| 語学スクール | 一定期間以上の契約を条件に教材費を無料化するキャンペーン |
| 携帯キャリア | 端末を一定期間後に返却すれば残債免除というプログラム（旧2年縛りの後継） |

### 3.2 評価

「一定期間の継続で特典を解放する」設計は、業界を問わず広く使われている**コミットメント期間に応じた特典解放の定石**であり、目新しい手法ではないが、実務上有効とされる型に沿っている。**この設計が実際にチャーン率をどの程度改善するかを示す定量的な一次データ（対照実験等）は確認できなかった。**

SaaS/サブスク業界一般では月次チャーンレート3〜10%が目安とされ、チャーン対策として「購入後フォローアップ」「会員限定特典」「ロイヤルティプログラム」等が一般的な施策として挙げられている（二次情報）。

## 4. 差別化分析

### 4.1 差別化の3層構造

| 層 | 内容 | 検証状況 |
|---|---|---|
| ①信頼性（案C） | 「実務者発の信頼性」。`ai_app_pro`氏の「教える専門家」ポジションと明確に異なる | 既存noteの貿易・AI-DX・金融コンテンツで既に一定の実務者ポジショニングを確立済み（最も検証されている） |
| ②機能設計（案A） | 「エージェント構成」と「UIの見た目」を独立した着せ替え要素にする設計思想 | **先行事例が見つからない＝差別化になり得る根拠であると同時に、需要が未証明という根拠でもある**（最も検証されていない） |
| ③特典設計（3階層＋キット配布） | 階層型サブスク＋3ヶ月継続特典 | 個々の要素は業界定石で目新しさはない。「貿易・海外展開支援という実務ドメイン×AIエージェントチームのデータファイル一式」という掛け合わせ自体は先行事例なし |

### 4.2 簡易ポジショニングマップ（定性・市場規模は断定しない）

| | 汎用・業種横断テンプレ寄り | 特化実務ドメイン発（実務者自身の運用実績）寄り |
|---|---|---|
| **低価格・買い切り** | `ai_app_pro`氏／`u_suke_37`氏（確認済み・直接競合） | 該当する直接競合は確認できず |
| **継続課金・個別伴走** | JAPAN AI AGENT・LUVO等の法人向けSaaS（価格非公開・業種横断） | **コホマダの想定ポジション**（貿易・海外展開特化、実務者発、3階層＋伴走） |

コホマダの想定ポジション（右下象限）に該当する直接競合は確認できていない。これは「空白市場」の可能性と「需要が検証されていないだけ」の可能性の両方を意味し、どちらか一方に断定できない。

### 4.3 総合評価

- 階層型サブスクを採用すること自体は標準的な設計判断であり、リスクではない。
- 差別化の主張は「先行事例がない」ことに依存しすぎず、①信頼性（検証済み）を土台に、②機能設計・③特典設計の価値をMVP検証で確かめる、という優先順位で進めるべき。
- 買い切り型が主流のnote/Brain市場でサブスク型に切り替えることは、決済手数料（定期購読25〜35%）や解約手続き対応など、買い切り型にはない運用負荷を伴う。

## 5. リスク・不確実性

1. **需要の一次データが存在しない**：「3階層サブスク＋3ヶ月継続特典」という具体的な商品設計そのものへの需要を裏付ける一次データはなく、MVP検証（フェーズ1のモニター）でしか確認できない。
2. **継続特典の告知文言が景品表示法・特定商取引法上の表示規制に抵触しうる**（例：「3ヶ月継続で無料プレゼント」という訴求が二重価格表示や誇大表現に該当しないか）。本レポートの調査範囲外であり、リョウ・弁護士確認が必要。
3. **近縁商品（Brain×Claude Code 13体AI制作ライン等）が今後サブスク型に転換する可能性**があり、MVP実行フェーズ中の定期的な競合ウォッチが必要。
4. 本調査はWebSearch／WebFetchによる二次情報中心であり、JavaScriptレンダリング依存ページ・Brain購入後専用ページ・非公開SaaS料金等は取得できていない。「確認できなかった＝存在しない」ではない。

## 6. 結論・推奨

1. 3階層の差別化軸は、業界定石（コンテンツ量・個別サポート・テンプレート/ファイル・コミュニティ・対応速度）に沿って設計し、無理に独自性を狙って複雑化しない（T85で既に反映済み）。
2. 「3ヶ月継続でキット配布」の告知文言は、外部公開前に必ずリョウ・アオイの確認を経る（景品表示法・特定商取引法の表示規制の観点）。
3. サブスク型競合が見つからなかった点は「差別化になり得る」根拠として使えるが、「先行事例がないから成功する」という論理にはならない。**MVP検証（フェーズ1：X＋note）の実データで需要を確かめる方針を最優先とする。**
4. 差別化戦略は3層構造（信頼性→機能設計→特典設計）のまま実行に移し、MVP検証ではこの3層それぞれへの反応を分けて観測する（①エージェント機能そのものへの評価、②UI着せ替え機能への評価を分けてヒアリング）。

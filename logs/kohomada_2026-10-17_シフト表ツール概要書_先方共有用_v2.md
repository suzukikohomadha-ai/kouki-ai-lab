## この資料について

この資料は、新宿駅西口店の皆さまに、トライアル版の「シフト表・フロコン表ツール」がどんな道具なのかを知っていただくためのご紹介です。パソコンが得意でない方にも読んでいただけるよう、専門用語はなるべく使わずに書いています。

- **対象**：ブックオフ様 新宿駅西口店で、シフト表やフロコン表を作る・見る方
- **前提**：10月5日に平田様から伺った、現場でのシフト作成とフロコン表作成のお話をもとに作りました
- **細かい操作手順**：別紙の「操作ガイド」に、画面つきでまとめています

## ひとことで言うと

**ハイソルシフトで決まった1週間分のシフトを取り込むと、売場ごとのシフト表と、時間ごとの担当を決めるフロコン表を、Excelが自動で作る道具です。** 表の「下書き」をツールが作り、人はそれを確かめて、必要なところを直します。

ツールが代わりにやることは、次の4つです。

1. **シフトを売場ごとに分ける**：取り込んだシフトを、「BO時短」「靖国」「ホビー・トレカ」「アパレル・家電」の4つの売場の表に並べます。
2. **フロコン表に業務を入れる**：休憩を先に置き、そのあと1日を30分ごとに区切って、必要な人数だけ業務を割り当てます。
3. **足りないところを知らせる**：必要な人数に届かない時間帯があれば、「確認一覧」に一覧で出します。
4. **1週間分をまとめて印刷する**：目次にある3つのボタン（BO・ホビトレ・アパ家）から、それぞれのフロコン表の月曜から日曜までを、まとめて印刷やPDFにできます。

自動で入った内容は、いつでも手で直せます。直した内容は記録されるので、別の日を見てから戻っても消えません。ただし、「リセット」や「フロコン表 一括作成」を押すと表が最初から作り直され、手で直した内容は消えます。

| --- | --- |
| ハイソルシフト | 今お使いのシフト管理の仕組みです。ここから1週間分のシフトをファイルで取り出します。 |

| 売場シート | 1週間分のシフトを、売場ごとにまとめた表です。「BO時短」「靖国」「ホビー・トレカ」「アパレル・家電」の4つがあります。 |
| 帯（おび） | 「BO朝番」「BO夜番」「ホビー朝番」のような、スタッフのグループ分けです。どの帯にいるかで、どの売場・どのフロコン表に載るかが決まります。 |

## 1週間の使い方

ハイソルシフトでその週のシフトが決まったら、週に1回、次の順で使います。取り込みで押すのは基本の2つのボタン（①と②）だけで、あとはツールが表を作ります。

［図：毎週の使い方・6つの手順］
1. ハイソルシフトからCSVを出す（月曜から日曜までの1週間分）
2. 「① CSV取込」を押す（スタッフ一覧のシートで、CSVを選ぶ）
   - 帯のない人がいる → その人を帯に入れる（▼で帯を選び、ボタンを押す）→ 3へ
   - いない → 3へ
3. 「② シフト表作成」を押す（売場シートとフロコン表が自動でできる）
4. 確認一覧を見る（取り込み直後は、初日の分が出る）
5. フロコン表を確かめて直す（業務は▼から選び直せる）
6. 目次から1週間分を印刷する（終わると1週間分の確認一覧が出る）

「帯のない人」は、新しく入ったスタッフなど、まだグループが決まっていない人のことです。その場合だけ、手順3の前に帯を選んでください。

## 画面（シート）の案内

ふだん使うのは、表の上から5つ（目次〜確認一覧）です。いちばん下の「基本設定・フロコン設定」は、売場や業務の決まりが変わったときだけ触ります。このほかに「フロコン(BO)」「フロコン記録」というシートもありますが、ツールが使う表なので触らなくて大丈夫です。

| シートの名前 | 何ができるか | 使うとき |
| --- | --- | --- |
| 目次 | 各シートへの入口です。1週間分の印刷ボタンと、月替わりの片付けボタンがあります。 | 印刷するとき・月が替わったとき |
| スタッフ一覧 | シフトを取り込むボタンがあります。スタッフがどの帯にいるかもここで決めます。 | 毎週（シフトが決まったら） |
| 売場シート（4つ） | 1週間分のシフトを売場ごとに見られます。前の週に切り替えることもできます。 | シフトを確かめるとき |
| フロコン表（3つ） | 1日分の担当表です。左上で日付を選ぶと、その日の表に切り替わります。 | 毎日の担当を確かめる・直すとき |
| 確認一覧 | 人数が足りない時間帯や、気をつけたい点を、「どうするか」と一緒に並べます。 | 取り込みや印刷のあと |
| ハイソル備考 | 最後に取り込んだ週について、スタッフがハイソルシフトに書いた希望やメモを、日付ごとに一覧で見られます。 | シフトの希望を確かめるとき |
| チェックリスト | 売場ごとのスタッフの一覧です。 | 必要なとき |
| 基本設定・フロコン設定 | シフトの時間（A番は9:30〜17:30 など）、業務の種類、時間ごとに必要な人数などの決まりごとです。 | 決まりが変わったときだけ |

## 使うときの約束ごと

安心して使っていただくために、次の5つだけ守ってください。

1. **開いたら「コンテンツの有効化」を押す**：画面の上に黄色い帯が出たら押してください。押さないとボタンが動きません。
2. **終わったら保存してから閉じる**：キーボードの Ctrl を押しながら S を押すと保存できます。保存しないと、その日の作業は残りません。
3. **日付や週は ▼ の一覧から選ぶ**：マスに直接打ち込まず、一覧から選んでください。
4. **スタッフを足すときは行を増やさない**：帯に空きがないときは、コホマダまでご連絡ください。
5. **月が替わったら新しい名前で保存してから始める**：例えば「2026年11月_シフト.xlsm」のように、月ごとに1つのファイルを使います（画面左上の「ファイル」→「名前を付けて保存」）。新しい月の最初の週を取り込んだら、目次の「前の月の写しを消す」を押して、前の月の分を片付けます。

**個人情報について**：ファイルやPDF、印刷した表には、スタッフの氏名や従業員番号が入ります。ファイルやPDFは、メールで送ったり、OneDriveやUSBメモリに置いたりしないでください。ファイルはお店のパソコンの中のフォルダに置いてお使いください。PDFは印刷したら消し、印刷した紙はお店のルールに沿って管理してください。

## 困ったとき

まず下の表を確かめてください。それでも直らないときは、表示されたメッセージの文章を書き写すか、メッセージの部分だけを写真に撮って（氏名や従業員番号が写らないように）、コホマダまでご連絡ください。

| こんなとき | こうしてください |
| --- | --- |
| ボタンを押しても何も起きない | ファイルを開き直して、「コンテンツの有効化」を押してください。 |
| 日付の一覧に、取り込んだ週の日が出ない | 「② シフト表作成」まで押したか確かめてください。 |
| 「シフトのある人がいません」と出る | 選んだ日付が、取り込んだ週の日か確かめてください。 |
| 「…で止まりました」と出る | メッセージの文章を書き写して（または、氏名が写らないようにメッセージだけを撮って）ご連絡ください。「保存せずに閉じてください」と出たら、保存せずに閉じて開き直してください。 |
| 取り込む前の状態に戻したい | 取り込みのたびに、同じ場所の「バックアップ」フォルダに控えが自動で保存されています。戻し方は操作ガイドの「12. 困ったとき」をご覧ください。 |

**お問い合わせ先**：平田様を通じて、株式会社コホマダまでご連絡ください

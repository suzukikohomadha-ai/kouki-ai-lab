# T107 調査報告：「スターターキット」単体商品（¥5,000〜10,000想定）の価格妥当性検証

担当：リサ（Research & Evidence Analyst）
基準日：2026-08-08
依頼元：社長（ジン経由）
対象：サブスクとは切り離した単体商品「Claude Codeベースの AIエージェントチーム設定ファイル一式（貿易・海外展開支援・実務者向け、1テーマのみ、業種テンプレ・教育コンテンツを含まない）」をnote経由で販売する場合の想定価格帯（¥5,000〜10,000）の妥当性

## 結論

1. **¥5,000〜10,000というレンジ自体は「割高」ではないが、レンジ内のどこに置くかで説得力が大きく変わる。** 唯一確認できている直接競合`ai_app_pro`氏の商品（9,800〜19,800円・7業種テンプレ・208ファイル・PDFマニュアル4冊込み）と比べると、今回の商品は「業種の幅（7→1）」はほぼ差し引きゼロ（買い手は元々1業種しか使わない）だが、**「マニュアル・FAQ・機能解説（＝教育コンテンツ）を含まない」という差は、買い手の自走負荷を明確に増やす実質的な価値の切り下げ**であり、ここが価格を下げる主因になる。
2. **「Claude Code関連の設定ファイルのみ（教育コンテンツを伴わない）」を単体販売している直接事例は、今回の調査範囲では確認できませんでした。** 近い候補（Gumroad「The Complete Claude Code Playbook」、note「CLAUDE.mdテンプレ集」）はいずれも解説・ガイド色が強く、「ファイルのみ・解説なし」という商品性質に一致しない（詳細は分析2節）。
3. note/Brainの個人発デジタル商品の一般価格帯は、note有料記事で実用ノウハウ系平均1,842円（300〜3,000円が主流帯）、Notionテンプレート単体で1,980〜3,980円（ボリュームゾーン500〜1,500円、高機能帯3,000〜10,000円）という水準が再確認できた。**Claude Codeのマルチエージェント設定一式は、単一Notionページや読み物系記事より制作・保守の複雑度が明らかに高く**、この一般帯をそのまま適用すべきではない。
4. 教育コンテンツ（マニュアル・FAQ・図解ガイド）を外すことは、①制作コストの削減、②買い手の自走負荷の増加、③サポート機能の欠如、という3つの意味を同時に持つ。①は売り手にとって値下げの余地だが、②③は買い手にとって価値の低下であり、**価格を下げる方向にのみ働く要因ではなく、「安いから許容できる」という説得材料と「安いのに使いこなせるか不安」という懸念材料の両方を生む**点に注意が必要。
5. **推奨価格：¥6,800（単発・買い切り）。** ¥5,000〜10,000のレンジ内で妥当と判断する。根拠は分析4節。`ai_app_pro`氏の参入価格（9,800円）より意図的に下げる一方、Notionテンプレートや読み物系note記事の相場（1,000〜4,000円台）よりは明確に高く設定する。理由は、（a）教育コンテンツを含まない分の価値低下を織り込みつつ、（b）マルチエージェント構成一式という制作複雑度・専門性は単一テンプレートより高いこと、（c）想定顧客（Claude Codeを既に使っている、または使う意思のある事業者）は価格感応度がやや低い層であること、の3点による。

## 推測・仮説

- 今回の商品（1テーマ・設定ファイルのみ）は、買い手にとって「7業種のうち自分の業種だけ使える`ai_app_pro`氏商品」と比べて、**実際に使う範囲では価値の目減りは小さい**と考えられる（買い手はどのみち自分の業種テンプレしか使わない）。むしろ「貿易・海外展開支援に特化」という専門性は、汎用7業種パッケージより刺さる買い手には強い訴求材料になり得る。[仮定]
- 一方、マニュアル・FAQ・図解ガイドを含まないことは、**買い手のセットアップ・活用における自走負荷を明確に増やす**。特にClaude Codeの操作に不慣れな買い手（貿易・海外展開の実務者は必ずしも技術者ではない）にとって、「動かし方が分からない」という離脱リスクが`ai_app_pro`氏商品より高い可能性がある。[仮定]
- 教育コンテンツを含まない分、鈴木さんの制作・保守コスト（マニュアル執筆・図解作成・FAQ整備の工数）は削減できると考えられるが、その削減分がそのまま販売価格に反映されるべきとは限らない（買い手側の価値も同時に下がるため）。[仮定]

## 分析

### 1. `ai_app_pro`氏商品との比較で、¥5,000〜10,000は割安か・妥当か・割高か

| 比較軸 | `ai_app_pro`氏（9,800〜19,800円） | 今回の商品（¥5,000〜10,000想定） | 影響 |
|---|---|---|---|
| 対象業種数 | 7業種 | 1業種（貿易・海外展開支援） | 買い手個人の実利用価値への影響は小さい（下げ要因として弱い） |
| マニュアル・FAQ・図解ガイド | PDF4冊（基本セットアップ・コマンドガイド・活用事例FAQ34問・全機能ガイド） | **なし** | 買い手の自走負荷が増える（下げ要因として強い。同時に制作コストの下げ要因でもある） |
| エージェント数・スキル・フック等の技術構成 | 16体・66スキル・9フック・12MCP設定 | `[未確認]`（依頼文からは規模不明。AICompanyの層A構成に準じるなら11体程度と推測されるが確定できない） | 規模が小さければ下げ要因、同等ならニュートラル |
| セットアップスクリプト（Mac/Windows対応） | あり | `[未確認]` | 無ければ自走負荷がさらに増える |
| 返金保証 | 実質なし | `[未確認]` | ニュートラル |
| 販売者のポジショニング | 「Claude Code講師」という教える専門家 | 「貿易・海外展開支援の実務者」という当事者（T85・T88で既に整理済みの差別化軸） | 信頼性の質は異なるが、価格の妥当性には直接影響しにくい |

**判定**：業種数の差（7→1）だけを理由に`ai_app_pro`氏の下限（9,800円）より大幅に安くする根拠は弱い（買い手は元々1業種しか使わないため）。しかし、**マニュアル・FAQ・図解ガイドという教育コンテンツを丸ごと含まないことは、実質的な商品価値の縮小であり、価格を明確に下げる根拠になる**。この2つの要因を差し引きすると、¥5,000〜10,000というレンジ自体は「割安すぎる」とは言えず、「`ai_app_pro`氏の下限（9,800円）に対してやや控えめに設定する」という方向性は理にかなっている。レンジの上限（10,000円）付近は`ai_app_pro`氏とほぼ同水準になり、教育コンテンツを含まない分の価値差が価格に反映されないため**割高側に振れるリスク**がある。レンジの下限（5,000円）は、note一般の実用ノウハウ系記事（平均1,842円）やNotionテンプレート（1,980〜3,980円）と比べれば明確に高く、**「割安すぎる」ことはない**が、マルチエージェント構成一式という制作複雑度を踏まえると、下限に寄せすぎる根拠も薄い。

### 2. 「設定ファイルのみ・教育コンテンツなし」直接事例が見つからないことの意味

先行事例が確認できなかったことは、T60・T84・T88が繰り返し指摘してきた構図（「差別化になり得る」根拠と「価値が未証明」根拠の両義性）と同じである。特に今回は、**「解説を削って安く売る」という設計そのものの先行事例が見つからない**ため、「ファイルだけを売る」という商品形態が市場に受け入れられるかどうかは未検証と考えるべきである。教育コンテンツを含む`ai_app_pro`氏商品が唯一確認できている直接競合であるため、価格の妥当性判断は同商品との比較が実質的な拠り所になる。

### 3. 「設定ファイルのみ・解説記事なし」という商品性質が価格の説得力に与える影響

- **下げる方向に働く要因**：マニュアル・FAQ・図解ガイドの制作コストが発生しない（売り手のコスト構造上は値下げ余地）。買い手から見れば「サポートが薄い分、安くて当然」という納得材料になり得る。
- **説得力を弱める・注意が必要な要因**：技術に不慣れな買い手層（貿易・海外展開の実務者は必ずしもエンジニアではない）にとって、「安いが使い方が分からない」という不満・低評価・返金要求のリスクが`ai_app_pro`氏商品より高くなり得る。教育コンテンツがない分、**最低限のセットアップ手順（インストール・初期設定の簡単な案内）くらいは商品に含めないと、「ファイルを渡されただけで何もできない」という失敗体験につながりやすい**。この場合、「教育コンテンツなし」と「セットアップ手順の最低限の案内」は区別して設計すべきであり、後者まで削ると価格以前に商品として成立しにくいリスクがある。[分析。この点は本調査の範囲を超える商品設計上の論点であり、ミナ・レンへの申し送り事項とする]
- 結論として、教育コンテンツを削ることは価格を下げる理由にはなるが、「安ければ安いほど良い」という単純な関係ではなく、**買い手が最低限自走できる水準を下回ると、価格を下げても満足度・評判が悪化するリスク**がある点に留意が必要。

### 4. 推奨価格の根拠

¥6,800を推奨する理由：

1. `ai_app_pro`氏の参入価格（9,800円）から、教育コンテンツ非包含分を差し引く形で、明確に下回る水準にする（約3割引）。
2. note一般の実用ノウハウ系記事相場（平均1,842円、上限3,000円程度）やNotionテンプレート相場（1,980〜3,980円）よりは明確に高く設定する。理由は、単一テンプレートや読み物記事と異なり、**複数エージェント・ルール・スキルが連携するマルチエージェント構成一式**は制作・保守の複雑度が高く、単一ページ・単一記事の相場をそのまま適用すべきではないため。
3. 想定顧客（Claude Codeを既に使っている、または使う意思のある貿易・海外展開実務の事業者・経営者）は、既に月額数千円のClaude Codeサブスクリプション自体に投資している層であり、一般的なnote読者より価格感応度がやや低いと考えられる（ただしこれは仮説であり、実データでの検証が必要）。
4. ¥5,000台（レンジ下限寄り）は「安すぎて質を疑われる」リスクと「マルチエージェント構成一式の制作価値を過小評価する」リスクがあり、¥9,800〜10,000（レンジ上限、`ai_app_pro`氏と同水準）は「教育コンテンツがないのに同じ値段」という割高感を招くリスクがある。¥6,800はこの両端を避けた位置づけである。

## リスク・注意点

1. **需要の一次データが存在しない**：¥6,800という提案価格を含め、「1テーマ・設定ファイルのみ」という商品性質への支払意思額を直接検証したデータはない。T90と同様、MVP的な少数先行販売・モニター価格での検証を推奨する。
2. **「安いから」という理由だけで購入した層が、セットアップでつまずき低評価・返金要求につながるリスク**（分析3節）。最低限のセットアップ案内（教育コンテンツとは別物として）を含めるかどうかは、価格設計そのものより先に検討すべき商品設計上の論点。
3. **noteの一般価格相場データに矛盾がある**（確認済み事実3節：「note実用系平均1,842円」説と「noteは平均500円前後」説が食い違う）。どちらも第三者の二次情報であり、note公式の一次データに今回到達できていないため、この矛盾は解消できていない。
4. **`ai_app_pro`氏商品は現在12,800円まで値上がりしており（当初9,800円から）、今後さらに値上がりする可能性がある**。今回の比較は2026-08-08時点のスナップショットであり、価格改定後は比較の前提が変わる。
5. 本調査は既存のT60・T84・T88と同じ制約（Gumroad等JS依存ページの詳細取得不可、日本語中心の検索範囲）を引き続き抱えている。「確認できなかった＝存在しない」ではない。
6. 「設定ファイルのみ・教育コンテンツなし」という商品を実際に告知する際の表現（「マニュアルなし」「サポートなし」等の明記）は、特定商取引法上の表示義務・誤認防止の観点から、外部公開前にリョウ・アオイの確認を経ることを推奨する（本調査は市場価格の検証のみであり、法令適合性の確認は範囲外）。

## 推奨案

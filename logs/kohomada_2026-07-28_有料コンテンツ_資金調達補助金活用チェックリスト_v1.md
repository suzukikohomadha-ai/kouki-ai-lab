# 有料コンテンツ素材：資金調達・補助金活用の実務チェックリスト（ミナ）

- 基準日：2026-07-28
- 位置付け：有料記事／チェックリスト素材の下書き（Draft）
- 前提：特定の補助金・助成金制度名や金額を挙げず（制度は年度・公募回によって変わるため）、**「公募要領をどう読み、どう活用可否を判断するか」という汎用的な実務フロー**として整理する。個別制度の最新情報が必要な場合は`subsidy-research`スキルで都度調査する。

## フェーズ1：資金調達手段の全体整理

- [ ] 自己資金・融資（日本政策金融公庫等）・補助金／助成金・出資（VC・エンジェル等）の選択肢を洗い出したか
- [ ] 補助金は「後払い（精算払い）が原則」であることを理解しているか（先に自社で立て替える資金繰りが必要）
- [ ] 融資と補助金の併用可否（制度による）を確認したか

## フェーズ2：公募要領の読み方

- [ ] 対象事業者の要件（業種・資本金・従業員数等）を満たすか確認したか
- [ ] 対象経費・対象外経費の区分を確認したか（人件費・設備費等、制度により扱いが異なる）
- [ ] 補助率・上限額を確認したか（制度により変動するため都度確認が必須）
- [ ] 公募期間・採択発表時期・事業実施期間の縛りを確認したか
- [ ] 他の補助金との併用禁止規定がないか確認したか

## フェーズ3：申請準備

- [ ] 事業計画書（課題・解決策・数値目標）を用意したか
- [ ] 見積書・相見積り（複数社比較）が必要な経費項目を洗い出したか
- [ ] 加点項目（賃上げ計画・DX推進等）に該当するものがないか確認したか
- [ ] 提出期限からの逆算スケジュールを組んだか

## フェーズ4：採択後・実行フェーズ

- [ ] 経費支出前に「交付決定」が出ているか確認したか（交付決定前の支出は対象外になる制度が多い）
- [ ] 証憑（領収書・契約書・支払い記録）の保管ルールを決めたか
- [ ] 実績報告書の提出期限・様式を確認したか
- [ ] 補助金入金までのタイムラグ（後払いによる資金繰り）に備えたか

## リスク・注意点

- 補助金・助成金の制度名・補助率・上限額を具体的に断定しない（年度・公募回で変わるため、架空の制度・数値を作らない）。実際の申請時は`subsidy-research`スキルで最新の公募要領を確認する運用とする。
- 「必ず採択されます」等の断定表現は使わない。

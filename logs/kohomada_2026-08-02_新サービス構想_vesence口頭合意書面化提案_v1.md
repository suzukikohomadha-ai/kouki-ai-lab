## 推測・仮説

- **［仮定］** 口頭合意のみで紹介料（成約時10%）の支払いが発生する取り決めが継続する場合、支払いの発生時期・金額についてvesence社側との認識齟齬が生じた際に、どちらの認識を優先すべきかを示す客観的な証拠が乏しくなると考えられる。
- **［仮定］** 準拠法・言語が明示されていない口頭合意は、仮に紛争化した場合、どの国の法律・言語で解釈すべきかという入口の論点自体が争いになりうる。日本・スウェーデンいずれの法律家が見ても、書面がない状態は法的立場の説明が困難になりやすいと一般的には考えられる［学説・実務見解／一般論］。

## 分析

### 1. 口頭のみの合意であることの法務リスク（今回の事実を前提とした整理）

T67では一般論として書面化の重要性に触れていたが、今回「実際に口頭合意のみである」ことが確定した事実として判明したため、以下は仮定ではなく本件に直接あてはまるリスクとして整理する。

**(a) 証拠力の弱さ・紛争時の立証困難**
口頭合意には、合意の存在・内容（特に「非独占」「成約時10%」という条件そのもの）を客観的に示す書面がない。将来、vesence社側の担当者が変わる、あるいはvesence社側の認識が変化するなどして「そのような合意はしていない」「条件が違う」と主張された場合、コホマダ側がメール・チャット履歴・議事録等の補助的な記録以外に合意内容を立証する手段が乏しくなる。特に「10%」「成約＝1年契約獲得時」という数値・定義は、書面がなければ解釈の余地が生まれやすい［学説・実務見解／一般論］。

**(b) 手数料の支払いを巡るトラブル時の対応の困難**
紹介料の発生条件（成約時）・料率（10%）は確認できたが、支払サイクル・通貨・請求方法・支払遅延時の扱いは未確認のままである。これらが書面化されていない状態で実際に成約案件が発生すると、「いつ・いくら・どの通貨で・どうやって」請求すべきかという実務上の取り決めがない状態で対応を迫られることになる。海外送金には為替・手数料・送金遅延等の実務的な論点も伴うため、これらが未整理のまま案件が進むこと自体が事業上のリスクになりうる（法務論点そのものではないが、T70・ミナの収益フレーム試算とも関連する）。

**(c) 準拠法・言語が不明であることによる不確実性**
合意が口頭であるため、準拠法・言語についての取り決め自体が存在しない可能性が高い。海外（スウェーデン）企業との合意である以上、万一の紛争時にどの国の法律・どの言語の解釈が優先されるかという入口の論点が未確定であり、これは通常の国際取引契約であれば書面上で明示的に定めるべき事項である［学説・実務見解／一般論］。

**(d) 対外表現・商標使用との関係での追加リスク（T67との接続）**
T67で整理した「対外呼称・商標使用の許諾範囲が未確認」というリスクは、合意が口頭であることによってさらに増幅される。書面による明示的な許諾がない状態で対外呼称・ロゴ使用の範囲を推測で広げると、後にvesence社側から「そのような許諾はしていない」と否定された場合に、コホマダ側に契約違反（口頭合意の解釈違反）・商標権侵害・不正競争防止法上の誤認惹起表示等、複数の法務リスクが重なって顕在化しうる。

**(e) 継続的な提携関係であることの特殊性**
今回の合意は単発の紹介ではなく、継続的な業務提携（紹介パートナーシップ）としての性質を持つ（T62・T65等の経緯から一般的にそう理解されている）。単発の口約束であれば実務上許容されることも多いが、継続的に紹介料が発生し続ける取引関係を口頭のみで運用し続けることは、時間の経過とともに「言った・言わない」のリスクが積み重なっていく点に留意が必要である。

### 2. 書面化（覚書・簡易契約書等）の推奨と含めるべき項目

早期の書面化を推奨する。形式は、正式な契約書でなくとも、双方が署名（またはメールでの明示的な合意確認）した覚書（Letter of Agreement / Memorandum of Understanding等）でも、口頭のみの状態よりは大幅に証拠力が向上する。`.claude/rules/contract-drafting.md`の作成前確認事項に沿い、少なくとも以下を含めることを推奨する。

| 項目 | 内容・確認状況 |
|---|---|
| 当事者の正式名称・所在地・締結者 | vesence社側の正式商号・所在地・締結権限者、コホマダ側の締結者を明記［未確認：締結者は要ヒアリング］ |
| 非独占の明記 | 「本提携は非独占とする」旨を明文化し、双方が他の同種提携を行いうることを明記 |
| 紹介料の発生条件 | 「成約（1年契約を獲得した時点）」の定義を具体的に記載（例：契約書の締結日か、初回請求発生日か等） |
| 紹介料率 | 10%と明記。何に対する10%か（契約金額の総額か、初年度分か、月額か等）を明確化 |
| 支払サイクル・通貨 | 現時点で未確認のため、書面化時に必ず確定させるべき項目 |
| 対外呼称の許諾範囲 | 使用してよい呼称（例：「日本語窓口」「紹介パートナー」等）、ロゴ・商標使用の可否・範囲・媒体 |
| 責任分担 | vesence社の製品に不具合が生じた場合のコホマダの説明義務の範囲、両社の責任の切り分け |
| 契約期間 | 分析3節参照。推奨案を提示 |
| 解約条件 | 予告期間、中途解約時の既紹介案件の扱い（解約後に成約した場合の紹介料の扱い等） |
| 準拠法・言語 | 日本法か、スウェーデン法か、あるいは中立的な第三国法か。言語は日本語・英語のいずれを正本とするか |
| 締結者・権限 | 双方の署名者が実際に合意する権限を持つか |

これらはあくまで書面に含めるべき項目の一般的な整理であり、実際の条項文言の起案（契約書ドラフト）は別タスクとして`contract-drafter`等に依頼することを推奨する。本報告は論点整理にとどまる。

### 3. 契約期間についての相場観（社長指示への回答・推奨案）

社長より「契約期間を定めなさい」との指示があったため、断定的な「これが正解」という結論は避け、一般的な紹介・代理店契約でよく見られるパターンを踏まえた選択肢を提示する。これは`statute-regulation-researcher`や`case-law-researcher`による一次情報の確認を伴わない、契約実務上の一般的な傾向の整理である点に留意されたい［学説・実務見解／一般論］。

**選択肢A：1年間・自動更新（双方異議なき限り）**
- 一般的な紹介・代理店契約でよく見られるパターンの一つ。初年度で提携の実態（実際に紹介案件が発生するか、双方にとって有益か）を検証できる。
- メリット：関係を継続しやすく、毎年の再締結の手間がかからない。
- デメリット：提携が形骸化・一方に不利益になった場合でも、解約通知を怠ると自動的に継続してしまう。解約条件（予告期間）を明確にしておく必要がある。

**選択肢B：1年間・都度更新（自動更新なし、双方合意で更新）**
- メリット：毎年、条件（料率・対外呼称の範囲等）を見直す機会が確保できる。vesence社がシード期スタートアップであり事業環境の変化が大きい可能性（T70でミナが指摘）を踏まえると、条件の見直し機会を定期的に持てる点は有用。
- デメリット：更新手続きを怠ると提携が意図せず終了してしまうリスクがある。更新の通知・確認プロセスを運用上明確にしておく必要がある。

**選択肢C：期間の定めなし（Evergreen）＋いつでも解約可能（予告期間付き）**
- 一部の紹介契約ではこの形式も見られる。
- メリット：更新手続きの手間がない。
- デメリット：関係の区切りが曖昧になりやすく、条件見直しのタイミングを意識的に作らないと、当初の条件（10%等）が事業環境の変化後も漫然と継続してしまう可能性がある。

**推奨の方向性（暫定・断定ではない）**
vesence社がシード期スタートアップであり事業継続性自体に不確実性がある点（T70でミナが指摘済み）、かつコホマダ側もプラン1をまだ「棚卸しレベル」に抑制する方針（T68・T66）である段階であることを踏まえると、**選択肢B（1年間・都度更新）**が、条件見直しの機会を確保しつつ関係を検証していく初期段階の提携としては相対的にバランスが取れていると考えられる［仮定］。ただし、これは一般的な傾向を踏まえた考え方の整理であり、最終的な期間設定は、事業判断（社長）と、書面化する際の弁護士確認を経て確定させるべきである。

### 4. T67「暫定的な対外表現の目安」の更新

条件が一部確定したことを踏まえ、T67の推奨案を以下のとおり更新する。T67の未確定だった項目（対外呼称・ロゴ使用範囲・責任分担・準拠法等）は依然不明のままであるため、その部分の慎重な扱いはT67から変更しない。

**今回追加で確定した事実を踏まえた更新点**

- **非独占であることが確定した**ため、「独占契約」「日本国内唯一の窓口」等、独占性を示唆する表現は、T67時点（未確認だった）以上に**明確な誤りとなる**。これらの表現は絶対に使用してはならない事項として扱う。
- **成約時10%の紹介料が確定した**が、この料率自体を対外的に開示してよいかどうかは、なお断定できない。
  - 一般的な商慣行としては、紹介料率・仲介手数料率は顧客等の第三者に開示しない扱いが多いとされる［学説・実務見解／一般論］。
  - ただし、合意が口頭のみであるため、vesence社との間で「料率を第三者に開示しない」という守秘義務・非開示条項が明示的に取り決められているかどうかは確認できていない［要ヒアリング］。
  - したがって、**10%という具体的な料率は対外的に開示しないことを当面の運用方針とする**ことを推奨する。開示してよいかどうかを確定的に判断するには、書面化の際にvesence社との間でこの点を明確にすることが望ましい。

**更新後の目安（T67からの差分のみ抜粋、それ以外の項目はT67の整理を維持）**

比較的慎重で、使える可能性が高いと考えられる表現の例（T67から変更なし）：
- 「vesence社の提供するAIエージェントプラットフォームをご紹介できる立場にあります」
- 「vesence社のプロダクトについて、日本語でのご相談窓口としてお手伝いしています」
- 「vesence社と連携し、導入のご相談を承っています」（"連携"の実態が事実であることが前提）

契約条件確認前は避けるべき表現の例（T67を維持し、独占性関連の表現を非独占確定によりさらに強く禁止事項として明記）：
- 「vesence社 正式代理店」「vesence社 認定パートナー」「vesence社 総代理店」等、公式な地位を断定する呼称（対外呼称の許諾範囲が依然未確認のため）
- **「独占契約」「日本国内唯一の窓口」「vesence社の日本総代理店」等、独占性を示唆する表現（非独占であることが確定したため、これらは単なる「未確認だから避ける」ではなく、事実に反する表現として明確に禁止）**
- vesence社のロゴ・商標を無許諾で営業資料・note記事等に掲載すること（許諾範囲が依然未確認）
- 「vesence社公認」「vesence社推薦」等、vesence社の公式な支持・推薦を示唆する表現
- **紹介料率（10%）を対外的に（顧客・note記事・営業資料等で）開示すること（当面は非開示運用を推奨。vesence社との合意で開示制限があるかどうか未確認のため）**

これらはあくまで一般的な整理であり、実際の書面化・弁護士確認を経て最終確定させるべきである［要弁護士確認］。

## リスク・注意点

- 口頭合意のまま紹介料が発生する案件（成約）が実際に生じた場合、支払いを巡る認識齟齬が起きても、それを客観的に解消する手段が乏しい。**書面化は、対外的な営業活動を本格化させる前、できれば直近の優先事項として進めることを推奨する。**
- 非独占であることが確定したにもかかわらず、営業資料・note記事等で独占性を示唆する表現を誤って使用すると、事実に反する表示として不正競争防止法・景品表示法上の論点に加え、vesence社との信頼関係悪化のリスクが生じる。
- 手数料率（10%）は現時点で未確定な支払サイクル・通貨と併せて書面化しない限り、実際の成約時に支払いの実務（いつ・いくら・どの通貨で・どのように請求するか）で混乱が生じる可能性がある。
- 対外呼称・ロゴ使用範囲・責任分担・vesence社側義務・締結者・準拠法は依然不明のままであり、T67で示した各種法務リスク（商標権侵害・不正競争防止法上の誤認惹起表示・景品表示法上の誤認表示・vesence社との契約違反）は解消されていない。

## 推奨案

1. **書面化を早期に進める。** 分析2節の項目リストをもとに、vesence社に対して覚書または簡易契約書の締結を提案することを推奨する。まずは非独占・紹介料条件（発生条件・料率）という既に口頭で合意済みの内容を書面に落とし込む形から始めれば、vesence社側の心理的ハードルも比較的低いと考えられる［仮定］。
2. **契約期間は、分析3節の選択肢の中から、社長の事業判断で選択する。** リョウとしては選択肢B（1年間・都度更新）を暫定的な方向性として示すが、最終決定は社長判断とする。
3. **対外表現は、更新後の目安（分析4節）に沿って運用する。** 特に「独占」を示唆する表現・紹介料率（10%）の対外開示は、書面化・vesence社との確認が完了するまで避けることを推奨する。
4. **T67で未回答のまま残っている項目（対外呼称・責任分担・vesence社側義務・締結者・準拠法）は、書面化の交渉の中で確定させることを推奨する。** 口頭合意の書面化は、単に「今の口頭合意を文書にする」だけでなく、これら未確定事項を確定させる機会として位置づけるとよい。

## 代替案

- 書面化の交渉に時間を要する場合、暫定的な措置として、既存のメール・チャットのやり取りがあれば、その中で「非独占」「成約時10%」等の合意内容に双方が言及した記録を明示的に残す（例：「先日ご確認いただいた条件、非独占・成約時10%で認識合わせできていますでしょうか」という確認メールをvesence社に送り、返信で明示的な同意を得る）ことで、正式な書面化までの間の証拠力を部分的に補強するという選択肢もある。ただし、これは正式な書面化の代替にはならない。

この変化から、次のように読めます。[推測]
- 「デリバリー用に値上げして手数料を吸収する」「複数のバーチャルブランドを量産する」という以前の勝ち方は使いにくくなっています。
- その分、**実店舗1つ・主力カテゴリ1つ・3プラットフォーム併用**で、評価と稼働率を積み上げるやり方が中心になると見ています。

### 1-4. 実践テクニック（確度の高い順）

**① Uber Eatsの「Eats厳選」の5指標を守る**［確認済み事実］
- 5指標は「星評価・注文数・オンライン率・見逃し注文・注文ミス」です。
- 過去90日の実績で毎月評価され、条件を満たすと上位に表示されます。
- 対象になるのは登録から90日以降です。

**② プロモーションは「原価の低い商品」と「条件付き」で設計する**［確認済み事実・ケバブ事例］
- BOGOは原価の低い2品に限定しています。
- 2週間のプロモが終わった後は、「1,500円以上／2,000円以上で割引」に切り替えて売上を維持しました。
- 広告は「20〜30%アップするイメージ」で、管理画面でABテストを回す、という運営者の発言があります（Kaya Group）。

**③ 空いている時間帯に営業する**［確認済み事実］
- 朝8時に開店して夜勤明けの需要を取る（cafe sun deco）。
- 本業の暇な時間帯をデリバリーで埋める（カラオケ店）。
- 深夜帯の効果を示す一次情報は見つかりませんでした。

**④ オペレーションでミスとキャンセルを防ぐ**［確認済み事実］
- 注文から1分以内に調理する（魚丼）。
- 温かいものと冷たいものを分け、トッピングは個別に包む。
- 調理準備時間は長めに設定する（30〜50分）。
- 調理能力を超えない数量にとどめる（厚労省リーフレット）。

**⑤ メニュー**
- 少額の単品で「ついで買い」を取る（串1本から注文可能）。
- サイドメニューをセットにして客単価を上げる。
- デリバリーに向く調理にする（水分を切る、浅い容器に小分けする）。

**⑥ リピーターを作る**
- レビューへの返信、サンクスカード、容器へのメッセージ。

### 1-5. 月商100万円の逆算［仮定・30日営業・手数料を引く前の売上］

| 客単価 | 月の注文数 | 1日あたり |
|---|---|---|
| 1,500円 | 約667件 | 約22件 |
| 2,000円 | 500件 | 約17件 |
| 2,500円 | 400件 | 約13〜14件 |

手元に残る額の試算（売上100万円の場合）

| 項目 | 金額 |
|---|---|
| 手数料35% | ▲35万円 |
| 原価30% | ▲30万円 |
| 包材5% | ▲5万円 |
| 販促10% | ▲10万円 |
| **人件費・家賃を引く前の残り** | **約20万円** |

- 手数料を税込38.5%で計算すると、残りは約16.5万円です。
- **月商100万円は「売上目標」としては現実的ですが、利益は別に設計する必要があります。** 既存店の空き時間を使わない新規店舗では、赤字になるリスクがあります。[推測]

### 1-6. リスク（論点の整理であり、法的な判断ではありません）

- **営業許可**
  - 飲食店営業許可が必要です。
  - 1つの許可で複数ブランドを営業できるかは[要保健所確認]。
  - 作り置きの弁当・惣菜は食品表示が必要になる場合があります。
- **景品表示法** [要弁護士確認]
  - 「お店と同じ価格」「○%OFF」の表示が、実際の支払額・店頭価格と一致しているか。
  - バーチャルブランドで「専門店」「手作り」と表示すること。
  - レビューに見返りを出す場合のステルスマーケティング告示。
- **プラットフォームの規約変更**
  - Uber Eatsのバーチャルレストランのように、戦略の前提が一方的に変わることがあります。
- **キャンペーン料率で計画しない**
  - ロケットナウの0%期間の利益率を前提に、事業計画を立てないでください。

## Part 2. 月商100万円を達成するための Claude Code 実行プロンプト

### 使い方

1. 下のプロンプトの `{ }` を埋めます。分からない項目は「不明」のままで構いません。Claudeが質問してきます。
2. このリポジトリを開いた Claude Code に、そのまま貼り付けます。
3. 毎月、実績データ（各社の管理画面の売上・注文数・評価・キャンセル率）を貼って **「月次レビューモード」** で再実行し、PDCAを回します。

### 設計のポイント（なぜこの形にしたか）

- **役割・目標・制約・手順・出力形式を分けた**：Claudeが「何を」「どこまで」「どの形で」返すかを迷わないようにするためです。
- **先にヒアリングしてから計画を作る**：業態・立地・実店舗の有無で戦略がまったく変わるので、推測で埋めさせないようにしています。
- **最新情報を毎回調べ直させる**：手数料・規約は2026年に大きく変わったので、調査を毎回のステップに入れています。
- **売上だけでなく利益でも判定する**：手数料35%の世界では、売上100万円でも赤字になりえます。
- **「事実／仮定／推奨」のラベルと承認ポイントを入れた**：社内のルール（evidence-policy・approval-policy）に合わせています。
- **エージェントの割り振りを指定した**：CLAUDE.md A-4のルーティング（リサ→ミナ→サトル→カエデ→リョウ→アオイ）に沿っています。

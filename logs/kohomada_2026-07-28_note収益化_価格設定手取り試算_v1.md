## 1. 確定した手数料構造（[確認済み事実]）

サービス利用料＝**事務手数料**（決済手段による）＋**プラットフォーム利用料**（事務手数料控除後の金額に対して）。別途、振込1回あたり**270円**（売上ごとではなく、振込のたびに1回のみ）。

| 決済手段 | 事務手数料 |
|---|---|
| クレジットカード | 5% |
| 携帯キャリア決済 | 15% |
| PayPay | 7% |
| Amazon Pay | 7% |
| noteポイント | 10% |
| PayPal | 6.5% |

プラットフォーム利用料（事務手数料控除後の金額に対して）：**有料記事・有料マガジン・チップ・メンバーシップ＝10%**、**定期購読マガジン＝20%**。

**重要な訂正**：以前T34で「二次情報」として記載していた「10%＋30円」という理解は不正確だった。正しくは決済手段ごとに変動する事務手数料（5〜15%）＋プラットフォーム利用料（10or20%）の二段構成であり、一律の固定額（30円）は存在しない。

## 2. 単発の有料記事・有料マガジン（プラットフォーム利用料10%）の手取り試算

1件あたりの手取り＝価格－事務手数料－プラットフォーム利用料（振込手数料270円は振込1回ごとに別途控除、都度の販売単価には影響しない）

| 決済手段 | 300円の場合の手取り | 500円の場合の手取り |
|---|---|---|
| クレジットカード（5%） | 257円（約86%） | 428円（約86%） |
| PayPay／Amazon Pay（7%） | 252円（約84%） | 419円（約84%） |
| PayPal（6.5%） | 253円（約84%） | 422円（約84%） |
| noteポイント（10%） | 243円（約81%） | 405円（約81%） |
| 携帯キャリア決済（15%） | 230円（約77%） | 383円（約77%） |

## 3. 定期購読マガジン（プラットフォーム利用料20%）の手取り試算

| 決済手段 | 500円/月の場合の手取り | 980円/月の場合の手取り |
|---|---|---|
| クレジットカード（5%） | 380円（約76%） | 745円（約76%） |
| PayPay／Amazon Pay（7%） | 372円（約74%） | 730円（約74%） |
| PayPal（6.5%） | 375円（約75%） | 734円（約75%） |
| noteポイント（10%） | 360円（約72%） | 706円（約72%） |
| 携帯キャリア決済（15%） | 340円（約68%） | 667円（約68%） |

**定期購読は単発より手取り率が7〜10ポイントほど低い**（プラットフォーム利用料が20%と単発の2倍のため）。これはT35で言及していた「定期購読は料率が高いという二次情報」を裏付ける結果。

## 4. 振込手数料（270円／振込1回）＋noteプレミアム月会費（定期購読のみ）の影響 [推計]

振込手数料は売上件数ではなく**振込1回あたり1回のみ**のため、購読者数・購入件数が少ないうちほど相対的な負担が重い。加えて、**定期購読マガジンを発行するにはnoteプレミアム（月額500円）への加入が固定費として必要**（[[kohomada_2026-07-28_note収益化制度調査_v1.md]] 4.5節・確定事項）。

例：定期購読500円（クレジットカード決済）を5人が購読した場合
- 月間売上：2,500円
- 月間手取り（振込手数料控除前）：380円×5人＝1,900円
- 振込手数料270円を引いた金額：1,630円
- **noteプレミアム月会費500円を引いた実質手取り：1,130円**（売上の約45%まで目減り）

**この固定費（振込270円＋プレミアム500円＝月770円）は購読者数に関わらず発生する**ため、定期購読を始める場合は最低限これを上回る購読者数・単価を見込めるかが損益分岐の起点になる。例えば月額500円なら、上記の固定費だけで元を取るには手取り380円/人として概ね2人以上の購読者が必要（770円÷380円≈2.03人）。

## 4.5 定期購読マガジンの運用上の必須条件（追加確定事項）

- noteプレミアム登録＋事前審査（申込み後、非公開状態で審査。通常1営業日程度）が必須。
- **月1回以上の更新が必須。更新がない場合、そのマガジンは停止・廃刊となる。** 既存の週次自動化ルーティン（隔週更新）を収益化用の定期購読マガジンにもそのまま流用できるなら条件は十分満たせる見込みだが、独立した新規マガジンとして作る場合は運用体制の継続が前提になる。
- **【確定】定期購読マガジンは運営中の価格変更が不可**。変更するには新しい定期購読マガジンを別途作成し、旧マガジンを終了させる必要がある。既存購読者は自動移行されないと考えられるため、値上げ・値下げのたびに購読者の再登録の手間・離脱が発生しうる。**これにより、定期購読の初期価格設定は「後で微調整する」前提を取れない**。単発の有料記事・有料マガジンで反応を見てから定期購読の価格を決める、という順番の方がリスクが低い[提案]。

## 6. 価格変更不可を踏まえた進め方の提案 [提案]

- 定期購読マガジンをいきなり本命の価格で始めず、まず単発の有料記事（価格変更可能）で反応・適正価格感を検証してから、定期購読の価格を決めるほうが手戻りが少ない。
- 定期購読を始める場合も、値下げの選択肢は事実上使いにくい（値下げ＝新マガジン作成＋既存購読者の再登録依頼になり評判リスクがある）ため、**やや保守的な価格（安全マージンを持たせた価格）から始める**方が無難[提案]。

## 5. T35の暫定価格帯の再評価

T35では単発300〜500円・定期購読月額500〜980円を暫定レンジとして提示していた。今回の確定手数料を踏まえても、この価格帯自体を変更する必要はないと考えられる（絶対的な手取り額は小さいが、率としては一般的な決済手数料の範囲内）。ただし、**定期購読を軸にする場合、月額を980円に近づけるほど手取り率は同じでも手取り額（絶対値）が大きくなる**ため、初期の購読者数が少ないと見込まれるなら、下限（500円）より上限寄り（700〜980円）を検討する余地がある[提案]。

## リスク・注意点

- 決済手段は購読者側が選ぶため、実際の手取りは決済手段の構成比に左右される（クレジットカード比率が高いほど手取りは良くなる）。
- 振込手数料・最低振込金額（未達の場合の繰越等）の詳細はこの共有情報には含まれておらず、[未確認]のまま。

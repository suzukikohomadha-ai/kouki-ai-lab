# ルール：機密保持・事業間の情報分離

## 1. 事業ごとの分離

コホマダ・KINOTO・個人FP事業は、法人格・顧客層・機密情報の性質が異なる別事業として扱う。

- ある事業の顧客情報・取引条件・内部事情を、他事業向けの成果物に混在させない
- 個人FP事業で扱う個人の家計・資産情報は、特に機微性が高いため、他の成果物に転記しない
- KINOTOの遺品整理・生前整理で知り得た情報（ご遺族の状況等）を、営業資料等の事例として無断で使用しない

## 2. 個人情報・機密情報の取り扱い

- 氏名・住所・電話番号・メールアドレス・家計/資産情報・取引条件等は、成果物内で可能な限り仮名・記号（`[顧客名]`等）に置き換える
- 外部AIサービス・外部ツール（本システム以外のAPI・ツール）へ個人情報・機密情報を入力する場合は、事前に`.claude/rules/approval-policy.md`に従い社長の承認を得る

## 3. トークン・認証情報

- APIキー・トークン・パスワード等の認証情報を、成果物・ログ・報告に平文で残さない
- `.env`等の認証情報ファイルを読み取る必要がある場合も、内容を報告に転記しない

## 4. n8n・自動化ワークフローとの関係

`mei-automation-architect`・`eito-n8n-engineer`が設計する自動化フローにおいて、事業を横断してデータを連携する設計をする場合は、どの事業のどの情報が連携されるかを明示し、`.claude/rules/approval-policy.md`の承認事項に該当しないか確認する。

## 5. 監査との関係

`aoi-quality-auditor`は、事業間の情報混在・個人情報の不適切な露出がある成果物を`REVISE`または`HUMAN REVIEW REQUIRED`とする。

# ルール：ファイル命名規則

## 1. 成果物（logs/）

```
logs/<事業タグ>_<YYYY-MM-DD>_<件名>_v<版数>.md
```

- 事業タグ：`kohomada` / `kinoto` / `fp` / `common`（複数事業共通）
- 例：`logs/kinoto_2026-07-25_公式LINE構築案_v1.md`
- 内容を変更する場合は版数を上げた新規ファイルを作る（上書きしない）。旧版は残す

## 2. サブエージェント定義（`.claude/agents/`）

- ファイル名は英小文字とハイフンのみ（例：`ryo-legal-compliance.md`）
- frontmatterの`name`とファイル名（拡張子を除く）を一致させる

## 3. Skills（`.claude/skills/`）

- フォルダ名は英小文字とハイフンのみ
- 詳細情報・テンプレート・チェックリストは`SKILL.md`と同じフォルダ内の補助ファイルに分離する

## 4. 実在する人物・法人の扱い

- 顧客・取引先の実名を、ファイル名にそのまま使用しない（案件ID・仮称・イニシャル等を用いる）
- 社内向け成果物であっても、個人情報を含むファイル名は避ける

## 5. アーカイブ

廃止事業・退役したエージェント定義等は削除せず、`_archive/<区分>/`配下へ移動する。移動時は元のフォルダ構造をできる限り保つ。

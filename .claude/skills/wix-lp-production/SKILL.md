# Wix / LP構成

詳細な構成項目は `structure.md` を参照。

## 使うタイミング

- KINOTO/コホマダのWebサイト・LPの構成案・改善案が必要なとき

## 要点

- 構成案（セクション構成・訴求順・CTA配置）はカエデが担当
- Wixの技術的な連携可否（外部埋め込み・API連携・パフォーマンス）はノヴァが確認する
- 実際のWix編集操作は社長が行う想定

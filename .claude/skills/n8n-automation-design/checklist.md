# n8n業務自動化 チェックリスト

## 要件定義（メイ）

- [ ] 対象業務のフロー（誰が・何を・どのツールで）を可視化したか
- [ ] 自動化によって浮く工数・コストを試算したか（`financial-analysis` Skillと連携）
- [ ] 人間の承認ポイント（どこで人が確認すべきか）を設計したか
- [ ] 障害時の代替運用（自動化が止まった場合どうするか）を設計したか

## 実装（エイト）

- [ ] ノードの正式名称・`type`・`typeVersion`・パラメータを公式ドキュメントで確認したか
- [ ] Credential Typeを確認したか（推測していないか）
- [ ] 確認できない項目に `[未確認]` `[要公式確認]` `[要インスタンス確認]` を付けたか
- [ ] 本番接続・Credential作成・有効化を、承認なしに実行していないか

## 共通

- [ ] 存在が確認できていないAPI・機能を利用可能と断定していないか
- [ ] 実際に実行・検証していないことを「動作確認済み」「デプロイ完了」と書いていないか
- [ ] `n8n-automation/` フォルダが存在する場合、そちらのルール・エージェント体制と矛盾していないか

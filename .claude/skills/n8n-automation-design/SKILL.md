# n8n業務自動化設計

詳細なチェックリストは `checklist.md` を参照。

## 使うタイミング

- 業務自動化の要件定義・n8nワークフローの設計/実装が必要なとき

## 要点

- まず業務フローを可視化し、自動化候補を抽出する（メイ）
- ノードの正式名称・API仕様・料金プランは推測せず、公式ドキュメントで確認する（エイト）
- 本番接続・Credential登録・有効化には社長の承認が必須
- `n8n-automation/` フォルダが存在する場合は、そちらの専任エージェント体制・ルールを優先して参照する

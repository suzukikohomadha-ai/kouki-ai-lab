# 短尺動画構成 リファレンス

## 基本構成（15〜60秒想定）

1. フック（最初の3秒・視聴を止めさせる一言/映像）
2. 課題提示（誰のどんな悩みか）
3. 解決（KINOTO/コホマダのサービスがどう解決するか）
4. 証拠（実績・事例・ビフォーアフター等、事実に基づくもの）
5. CTA（LINE登録・問い合わせ等、行動を1つ）

## KINOTO向けの観点

遺品整理・生前整理等はセンシティブなテーマのため、ビフォーアフターの見せ方・ご遺族への配慮を優先する。誇張した演出（過度な感動演出等）は避ける。

## コホマダ向けの観点

海外展開・DX事業紹介など、対象視聴者（経営者層等）に合わせたトーン・専門用語の使用可否を検討する。

## 禁止事項

- 実績・効果を誇張しない
- 撮影・編集の完了を、実際に行っていないのに報告しない

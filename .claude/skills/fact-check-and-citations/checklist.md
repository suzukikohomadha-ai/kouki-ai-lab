# 出典・事実確認チェックリスト

成果物を提出する前に、以下を確認する。

- [ ] 会社名・制度名・法令名・補助金名は、実在すると確認できたものだけを使っているか
- [ ] 重要な数値（料金・統計・期限・金額）に出典が付いているか
- [ ] 出典にURL・発行主体・公開日または更新日・確認日が記録されているか
- [ ] 一次情報が見つからなかった事項に「未確認」と明記しているか
- [ ] 情報源同士が矛盾していないか。矛盾がある場合は両論併記しているか
- [ ] 「確認済み事実」「推測・仮説」「提案」が文章上で区別できているか
- [ ] 法務・金融・税務・補助金・許認可について、断定的な結論（「合法です」「必ず採択されます」等）を書いていないか
- [ ] 実行・検証していない処理を「完了しました」と書いていないか

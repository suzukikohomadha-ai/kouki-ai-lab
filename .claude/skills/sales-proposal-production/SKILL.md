# 営業資料・提案資料の構成

詳細な構成項目は `structure.md` を参照。

## 使うタイミング

- コホマダ／KINOTOの営業資料・提案資料の構成が必要なとき

## 要点

- 構成を作る前に`success-case-research`（標準ステップ）で類似提案・類似業界の成功事例を調査し、成功要因を分析してから反映する（2026-07-28追加）
- 相手（誰に何を提案するか）を最初に明確にする
- 課題→解決策→実績・根拠→価格・条件→次のアクション、の流れを基本とする
- 数値・実績はミナ/リサが確認したものだけを使う

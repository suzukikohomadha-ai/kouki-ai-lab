# SNS運用

詳細な手順は `reference.md` を参照。AI美女アカウント事業（廃止済み）向けの固有運用ルールは除外し、汎用的な手順のみを収録している。

## 使うタイミング

- コホマダ／KINOTOのSNS（Instagram等）運用戦略・投稿計画・競合調査

## 要点

- 投稿計画を作る前に`success-case-research`（標準ステップ）で他社の集客成功事例を調査し、成功要因を分析してから反映する（2026-07-28追加）
- 投稿目的（認知／集客／信頼構築）を先に決める
- 投稿計画はKPI（インプレッション・エンゲージメント・遷移数等）と紐づける
- 競合SNS調査はリサに依頼し、リサの調査結果を根拠にする
- 実際の投稿・返信・公開操作は社長が行う（代理実行しない）

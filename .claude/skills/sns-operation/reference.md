# SNS運用 リファレンス

## 投稿計画の型

| 項目 | 内容 |
|---|---|
| 目的 | 認知／集客／信頼構築のいずれか |
| ターゲット | 誰に届けたいか |
| テーマ | 投稿の切り口 |
| 頻度 | 週あたりの投稿数 |
| KPI | インプレッション・エンゲージメント率・遷移数等 |

## 競合SNS調査の観点（リサと連携）

フォロワー数・投稿頻度・エンゲージメント率・伸びている投稿の傾向・ハッシュタグ戦略

## 収益化導線設計の観点

SNS→公式LINE→問い合わせ・申込、のように導線を明示する。KINOTOであれば「投稿→LINE登録→無料見積り」等、コホマダであれば「投稿→資料請求→商談」等、事業ごとに導線を具体化する。

## 禁止事項

- 実際の投稿・返信・公開操作を代理実行しない（社長が行う）
- フォロワー数・エンゲージメント率等の実績を推測で作らない
- AI生成物を使う場合はAI利用の開示ルール（`.claude/rules/security-policy.md` 等、社内ポリシーがあれば従う）を確認する

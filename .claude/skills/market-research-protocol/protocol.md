# 市場調査プロトコル（詳細）

## 手順

1. **検索語設計**：対象事業（コホマダ／KINOTO／FP）・地域・論点から複数パターンの検索語を作る
2. **情報源の優先順位**（`.claude/rules/evidence-policy.md` と共通）
   1. 社長提供の一次資料
   2. 公式サイト・官公庁・業界団体の公式資料
   3. 信頼できる業界レポート・統計
   4. 補助的な第三者情報（ブログ・まとめサイト・SNS）※これだけを根拠に断定しない
3. **記録項目**：出典名／URL／発行主体／公開日または更新日／取得日／該当箇所
4. **事実・推測・仮説の分離**：`[確認済み事実]` `[推測・仮説]` `[未確認]` のラベルを使う
5. **矛盾の確認**：複数の情報源が食い違う場合、両論併記し「どちらが優先されるべきか」の判断根拠を示す
6. **調査上の限界の明記**：検索範囲・検索語・確認できなかった点を必ず最後に書く

## 依頼元別の観点

- レンへの調査：市場規模・競合・進出先の商習慣
- ミナへの調査：制度・補助金・料金相場
- リョウへの調査：法令・許認可・行政解釈（ただし法的結論はリョウが整理し、リサは一次資料の存在確認に留める）

## 分析フレームワーク（2026-07-28追加）

調査結果を整理する際、目的に応じて以下の標準フレームワークを使う。フレームワークは「思考を整理する道具」であり、
枠を埋めること自体が目的化しないよう注意する（埋まらない項目は`[未確認]`のまま残す）。

- **3C分析**（Customer／Competitor／Company）：市場・顧客・競合・自社の関係を整理する際の基本形。新規事業検討・KINOTOの地域競合調査で使う
- **SWOT分析**（Strength／Weakness／Opportunity／Threat）：自社の強み弱みと外部環境の機会脅威を分けて整理する。事業戦略の前提整理に使う
- **PEST分析**（Politics／Economy／Society／Technology）：マクロ環境要因の整理。海外展開・制度調査（FP・補助金等）でPolitics/Economyの視点に使う
- **5フォース分析**（新規参入・代替品・買い手交渉力・売り手交渉力・業界内競合）：新規事業・新市場参入の競争構造を整理する際に使う（毎回フルセットで使う必要はなく、該当する力だけ抜き出してよい）
- **ペルソナ設計の観点**：年齢層・居住地域・課題・情報収集行動・意思決定者（本人か家族か等）を整理する。KINOTOの遺品整理・生前整理のように意思決定者と利用者が異なるケースは特に明記する

いずれのフレームワークも、枠内の記述は`[確認済み事実]`（出典あり）と`[推測・仮説]`を明確に分けて記入する。

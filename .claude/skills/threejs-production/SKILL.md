# Three.js制作

詳細なチェックリストは `checklist.md` を参照。

## 使うタイミング

- 3D企業サイト・インタラクティブ3D表現・商品ビューア等の企画・実装・検証

## 要点

- 公式ドキュメント（threejs.org）を優先し、使用するThree.jsのバージョンとの互換性を確認する
- パフォーマンス（読み込み速度・モバイル端末での動作）とアクセシビリティを検証する
- 存在しない/非推奨のAPIを確認なしに使用しない

# Three.js制作チェックリスト

## 実装前

- [ ] 使用するThree.jsのバージョンを確認したか
- [ ] 対象ブラウザ・対応デバイス（PC/モバイル）を確認したか
- [ ] Wixサイトへの埋め込みが必要な場合、連携可否を技術検証したか（`wix-lp-production` Skillと連携）

## 実装

- [ ] 公式ドキュメントで存在を確認したAPI・ジオメトリ・マテリアルのみを使用しているか
- [ ] パフォーマンス（ポリゴン数・テクスチャサイズ・描画負荷）を考慮しているか
- [ ] モバイル端末での動作・タッチ操作を考慮しているか
- [ ] アクセシビリティ（代替コンテンツ・reduced-motion対応等）を考慮しているか

## 検証

- [ ] 実際に動作確認したブラウザ/デバイスを明記しているか
- [ ] 検証していない環境について「未検証」と明記しているか

## 禁止事項

- 動作確認していないコードを「動作確認済み」と報告しない
- 非推奨・存在しないAPIを確認なしに使用しない

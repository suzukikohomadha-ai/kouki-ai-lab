# コピーライティング リファレンス

## 基本の型

1. ターゲット（誰に）
2. 悩み・欲求（何に困っている／何を望んでいる）
3. 提供価値（自社の何がそれを解決するか）
4. 根拠（実績・仕組み・第三者評価など、断定できる事実のみ）
5. CTA（次に取ってほしい行動を1つだけ）

## プロフィール文・紹介文の型

「誰向けの／何をする／どういう価値観の」事業者かを3行以内で伝える。数字を使う場合は出典を明記できるものだけを使う。

## CTA作成の観点

- 行動を1つに絞る（「LINE登録する」「資料請求する」等）
- 行動のハードルを下げる文言を添える（所要時間・無料の範囲等、事実に基づくもの）

## 禁止事項

- 実績・効果を誇張しない（`.claude/rules/evidence-policy.md` 準拠）
- 医療・金融・法律に関わる断定的な効果表現（「必ず治る」「絶対に儲かる」等）を使わない
- KINOTOのサービス（遺品整理・生前整理等）は、ご遺族・高齢者向けの配慮ある言葉選びをする

## コピーの型（2026-07-28追加）

用途・媒体に応じて以下の標準フレームワークを使い分ける。どれか1つに固執せず、媒体（チラシ／SNS投稿／LP／営業資料）と接触時間の長さに合わせて選ぶ。

- **AIDA**（Attention注目→Interest関心→Desire欲求→Action行動）：チラシ・バナー等、短時間で読まれる媒体の基本構成
- **PAS**（Problem課題→Agitate課題の深掘り→Solution解決策）：悩みが明確な層への訴求（KINOTOの不用品回収・遺品整理等）に向く。ただし「あおる」表現が過度にならないよう、事実に基づく範囲に留める
- **PREP**（Point結論→Reason理由→Example具体例→Point結論の再提示）：営業資料・LP・公式LINEの長文説明で使う
- **FAB**（Feature特徴→Advantage利点→Benefit読み手にとっての価値）：自社目線の説明（Feature）で終わらせず、必ずBenefitまで翻訳する。「要点」の2番目原則と対応する

## 見出し・キャッチコピー作成の観点

見出しは「具体性」「読み手にとっての得」「今読む理由」の3点を満たすと反応が上がりやすいとされる（実務上の経験則であり、断定的な効果を保証するものではない）。数字・固有名詞を入れると具体性が上がるが、事実確認できない数字は入れない。

# 公式LINE設計 リファレンス

## 友だち追加導線の例（KINOTO想定）

チラシ／Instagram／Webサイト／MEO（Googleビジネスプロフィール）→ 公式LINE友だち追加 → 自動応答（サービス案内・無料見積り誘導）

## リッチメニュー構成の型

| ボタン | 遷移先 |
|---|---|
| サービス一覧 | 古物買取・不用品回収・遺品整理・生前整理・家じまい・引越し・清掃・リフォーム紹介の案内 |
| 無料見積り | フォームまたはトーク誘導 |
| よくある質問 | FAQ |
| 会社概要 | 対応エリア・実績等 |

## 自動応答シナリオ設計の観点

初回メッセージ→サービス選択→簡易ヒアリング→見積り/問い合わせへの引き継ぎ、という流れを基本とする。個人情報（氏名・住所・電話番号等）を収集する設計にする場合、利用目的の明示・同意取得の設計を含める。

## 禁止事項

- 個人情報の取得・保存方法を確認せずに設計を確定しない
- 配信・実際の運用開始は社長の承認を経てから

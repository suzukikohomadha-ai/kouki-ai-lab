# 財務分析プロトコル

詳細な計算式・様式は `templates.md` を参照。

## 使うタイミング

- コホマダ／KINOTO/FP事業いずれかの収支分析・価格設定・損益分岐点分析

## 要点

- 前提条件（売上単価・原価率・固定費・変動費）を明示してから計算する
- 数値の出典（社長提供／推定）を必ず区別する
- 推定値を使う場合は根拠と前提条件を明記する
- 税務・法務上の適法性の断定はしない（`.claude/agents/mina-finance-fp-analyst.md` の禁止事項参照）

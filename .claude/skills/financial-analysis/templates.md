# 財務分析テンプレート

## 損益分岐点分析

```
損益分岐点売上高 = 固定費 ÷ (1 - 変動費率)
変動費率 = 変動費 ÷ 売上高
```

前提条件（固定費の内訳・変動費の内訳・売上単価）を必ず併記する。前提が社長提供でない場合は `[推定・要確認]` を付す。

## 価格設定検討の観点

原価・競合価格（リサの調査結果）・顧客が支払える範囲・利益率目標・KINOTOやコホマダの各サービスの繁忙度合いを踏まえる。断定的な「この価格が正解です」という表現は避け、複数案（下限・推奨・上限）を提示する。

## 禁止事項

- 実在しない統計・料金相場を作らない
- 税務上の扱い（経費計上の可否等）を断定しない。個別具体的な税務判断は税理士確認が必要と明記する
